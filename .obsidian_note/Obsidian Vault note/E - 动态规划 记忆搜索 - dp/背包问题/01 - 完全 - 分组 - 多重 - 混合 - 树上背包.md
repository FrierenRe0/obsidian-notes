# 分组背包：

**本质：和0-1背包并无两样**

可以这样对比：0-1背包和组合背包的区别是：
 - 0-1背包每一层因只有一个元素，所以只是每层依次枚举该元素即可；
 - 组合背包每一层不再是一个元素了，而是一个集合(一个集合里面可能存在多个元素)，每层则是需要遍历集合中所有可能选择的元素;

总结下来：
- 说白了，组合背包就是在0-1背包的基础上因为每一层不在是单一元素选项，存在多个元素选项，在加一层暴力枚举集合中的元素就是了，其他的同理；

## 注意：

这里有个**易错点** : 在倒序遍历一层中的背包大小时一定要**注意顺序** -- 是先遍历完这一层集合中所有可以选择元素，再去遍历（前一个/下一个）节点;

解释：和用一维数组优化的倒序遍历的解释相同，都是因为一层中至多只可以选一次，避免在一层中出现数据迭代混乱（准确来说：如果不是按照该顺序该层的节点信息就有可能是因为选择了多个元素累加出来的数据，从而发生数据混乱）;

## 例题：
- [4040. 构造子集和的最少操作次数 I](https://leetcode.cn/problems/minimum-operations-to-form-subset-sum-i/)
- [4041. 构造子集和的最少操作次数 II](https://leetcode.cn/problems/minimum-operations-to-form-subset-sum-ii/)

两个题目大同小异：
区别在于每层一个元素对应所等产生的集合，在题目条件的不同下，所能产生的子元素可能不同，但是在算法逻辑上是一致的；

### 代码参考：
[4040. 构造子集和的最少操作次数 I](https://leetcode.cn/problems/minimum-operations-to-form-subset-sum-i/)
```c++
class Solution {
public:
    //分组背包
    int minOperations(vector<int>& nums, int sum) {
        vector<long long> dp(sum + 1,INT_MAX);
        dp[0] = 0;
        for(auto& x : nums) {
            int w = bit_width((size_t) x);
            for(int i = sum;i >= 0;i--) {
	            //遍历该层集合：
                //一维数组优化：
                //1. (元素大小 > i) -> dp[j] = dp[j],无意义;
                //2. 只看(元素大小 <= i) 即可;
                //遍历每个集合的选择情况：
                for(int a = 0;(x << a) <= i;a++) {
                    dp[i] = min(dp[i],dp[i - (x << a)] + a);
                }
                
                for(int a = w - 1;a && (x >> a) <= i;a--) {
                    dp[i] = min(dp[i],dp[i - (x >> a)] + a);
                }
            }
        }
        return dp[sum] == INT_MAX? -1 : dp[sum];
    }
};
```

```c++
    }
```

## 在这种情景下怎么解决怎么解决这种问题 (从暴力到优化 -> 时间上)

### 朴素枚举：

背包问题往往是可以相互转化，我之所以把多重背包放在分组背包之后，是因为多重背包在暴力枚举的思考角度上雷同于分组背包;
#### 这里我通过这道例题作为引入 :

模板题：[P1776 宝物筛选 - 洛谷](https://www.luogu.com.cn/problem/P1776#ide) -> 解决最值

![](../../../截图文件/Pasted%20image%2020260909115054.png)

#### 题目说明与分析

**问题描述：**

给定 $N$ 种物品和一个容量为 $W$（代码中的 `rap`）的背包。每种物品包含三个属性：

- 价值 $v$ (`a[i][0]`)
    
- 体积/重量 $w$ (`a[i][1]`)
    
- 数量限制 $m$ (`a[i][2]`)


目标是选择若干物品装入背包，在总体积不超过 $W$ 的前提下，使获得的**总价值最大**。

#### 暴力 DP 解法思路

**状态定义：**

`dp[t]` 表示当前背包容量为 $t$ 时能获得的最大价值。

**状态转移方程：**

对每种物品 $i$，我们枚举它的选择数量 $c$ ($0 \le c \le m$ 且 $c \times w \le t$)：

$$dp[t] = \max_{c=0}^{\min(m, \lfloor t/w \rfloor)} \{ dp[t] + c \times v, \ dp[t - c \times w] + c \times v \}$$

为了防止同一件物品在一个阶段被重复选择多次，倒序遍历背包容量 $t$（从 $W$ 到 $0$）。

#### 朴素算法代码展示：

#### 暴力 - 时空复杂度

- **时间复杂度：** $O(N \times W \times \sum m)$ 或 $O(N \times W \times \min(m, W))$
    
    核心包含了三重循环：遍历物品 $N$、倒序遍历容量 $W$、枚举选取数量 $m$。当 $N, W, m$ 较时会产生超时(TLE)
    
- **空间复杂度：** $O(W)$（使用一维滚动数组压缩空间）





### 优化1:（二进制优化）将朴素枚举每种商品的个数改为二进制分块包装

#### 注意：二进制拆分适用于**多重背包求最值或可行性**（0-1 状态，如能否凑出某金额、最大价值），**不能用于求方案数**。

举例：
1. **重复统计方案（Double Counting）**
    
    - 假设某种题目有 $3$ 道，分值 $v = 1$。
        
    - 二进制拆分会将其拆成两个物品：权值 $1$ 和 权值 $2$。
        
    - 假设目标要凑成 $3$ 分：
        
        - **正确情况**：只有一种方案（即选用 $3$ 道 $1$ 分的题）。
            
        - **你的代码**：拆出权值 $1$ 和权值 $2$ 后，按 0-1 背包方案数计算，取权值 $1$ + 取权值 $2$ 会被当作一种方案，而导致底下小状态如：`dp[0]或者dp[2]`存在重复计算的错误组合方式。
            
2. **本质：忽略了“同一组题”的互斥限制**
    
    - 同一种类型的题目，选 1 道、2 道、3 道是**互斥的同组选择**。
        
    - 0-1 背包拆分后，系统会把“选 1 道”和“选 2 道”当成两个独立物品同时选中，打破了正确计数的逻辑。


#### 算法核心思想

在多重背包中，某种物品有 $cnt$ 个。如果直接枚举选 $0, 1, 2, \dots, cnt$ 个，效率非常低。

**二进制拆分原理：**

任何一个正整数 $cnt$ 都可以唯一拆分为 2 的幂次组合 $1, 2, 4, 8, \dots, 2^k$ 以及一个余数 $R$（其中 $R = cnt - (1 + 2 + 4 + \dots + 2^k)$）。

这些拆分出来的系数组合，可以**无重复、无遗漏**地凑出 $0 \sim cnt$ 之间的任意整数。因此，我们可以把数量为 $cnt$ 的单个物品，拆分成 $\log_2(cnt)$ 个“捆绑打包”的新物品，每个新物品只能“选”或“不选”，从而直接转化为 **0-1 背包问题**。

#### 二进制拆分过程
-> 以物品数量 $cnt = 13$ 为例：

- 拆出 $c = 1$，剩余 $cnt = 12$
    
-  拆出 $c = 2$，剩余 $cnt = 10$
    
-  拆出 $c = 4$，剩余 $cnt = 6$
    
-  下一步本应拆 $8$，但剩余的 $6 < 8$，停止循环，将剩余的 $6$ 作为一个整体
    
-  最终拆分系数为：$\{1, 2, 4, 6\}$
通过组合 $\{1, 2, 4, 6\}$，能够表达出 $[0, 13]$ 范围内的任意整数。原先需要枚举 14 次的选择，现在只需考虑 4 个新物品的选或不选。

C++
**二进制分块模板：**
```
void f(int v, int w, int cnt) {
    for (int c = 1; c <= cnt; c <<= 1) {
        val.push_back(c * v);      // 捆绑后的新价值
        weight.push_back(c * w);   // 捆绑后的新重量
        cnt -= c;
    }
    if (cnt) {                     // 处理剩余不足 2^k 的部分 R
        val.push_back(cnt * v);
        weight.push_back(cnt * w);
    }
}
```

#### 0-1 背包求解

将拆分出的所有新物品存入 `val` 与 `weight` 数组后，直接套用标准 0-1 背包的一维 DP 滚动数组模板：

$$dp[t] = \max(dp[t], \ dp[t - weight[i]] + val[i])$$
C++
**一维0-1背包模板：**
```
n = val.size(); // 拆分后的总物品数
vector<int> dp(rap + 1);
for (int i = 0; i < n; i++) {
    int x = weight[i];
    for (int t = rap; t >= x; t--) { // 倒序遍历容量，确保每个新物品只选一次
        dp[t] = max(dp[t], dp[t - x] + val[i]);
    }
}
```

#### 复杂度分析

- **时间复杂度：** $O(W \cdot \sum \log_2 m_i)$
    
    每个数量为 $m_i$ 的物品被拆分为 $\log_2 m_i$ 个新物品。拆分后的新物品总数大约为 $N' \approx N \log_2 M$。随后进行一次 0-1 背包，总时间复杂度由暴力的 $O(N \cdot W \cdot M)$ 大幅优化至 $O(W \sum \log_2 m_i)$。
    
- **空间复杂度：** $O(W + N \log_2 M)$
    
    用于存放 DP 滚动数组（$W$）以及拆分后的新物品数组（$N \log_2 M$）。





### 优化2：(单调队列优化) 因为允许分组同余的背包大小，单调队列优化处理窗口极值从而达到维护每个背包极值的目的

#### **算法原理**：

**以 $mod = 0  \ \ \texttt{->} \  \ v(cost) = 2,cnt = 2$ 为例的单对优化示意过程：**
![](../../../截图文件/Pasted%20image%2020260910153156.jpg)

对于第 $i$ 种物品，状态转移方程为：

$$dp[j] = \max_{0 \le k \le c_i} \{ dp[j - k \cdot v_i] + k \cdot w_i \}$$

若直接转移，单次复杂度为 $O(V \cdot c_i)$。由于所有转移点都相差 $v_i$ 的整数倍，我们可以按余数 $mod \in [0, v_i - 1]$ 将所有状态划分为 $v_i$ 个独立的同余类。

对于同余类中的某个状态 $l$，令转移点为 $j = l - k \cdot v_i$（其中 $0 \le k \le c_i$），变形可得：

$$dp[l] = \max \{ dp[j] - \frac{j}{v_i} \cdot w_i \} + \frac{l}{v_i} \cdot w_i$$

定义状态价值函数：

$$value(i, j) = dp[j] - \lfloor \frac{j}{v_i} \rfloor \cdot w_i$$

转移方程简化为滑动窗口求最大值：

$$dp[l] = \max_{j \in [l - c_i \cdot v_i, l]} \{ value(i, j) \} + \lfloor \frac{l}{v_i} \rfloor \cdot w_i$$

**倒序滑动窗口实现细节**

1. **同余分组**：遍历余数 $mod \in [0, \min(t, v_i - 1)]$。
    
2. **预填充窗口**：倒序滑动时，先将初始窗口右侧的前 $c_i$ 个状态 $j = (t - mod) - k \cdot v_i$ 压入单调队列，维护 $value(i, j)$ 的单调递减性。
    
3. **窗口滑动与更新**：
    
    - 逐步向左移动 $l$ 和 $r$，新入队端点为 $r = l - c_i \cdot v_i$。若 $r \ge 0$，将其按单调性压入队列。
        
    - 取队头最优解更新 $dp[l] = value(i, dq.front()) + \frac{l}{v_i} \cdot w_i$。
        
    - 当队头元素等于当前右边界 $l$ 时，说明该点将在下一步超出窗口范围，执行 `pop_front()`


#### 单调队列优化代码展示：

```c++
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define endl '\n'
#define ctz __builtin_ctzll         // 二进制表示中末尾连续0的个数
#define clz __builtin_clzll         // 二进驻表示中先导0的个数
#define count1 __builtin_popcountll // 二进制表示中1的个数
const int MOD = 998244353;
const int N = 2e5 + 7;

vector<int> v,w,cnt;

void solve() { 
    int n,t;
    cin >> n >> t;
    v.resize(n);
    w.resize(n);
    cnt.resize(n);
    for(int i = 0;i < n;i++) {
        cin >> w[i] >> v[i] >> cnt[i];
    }

    vector<int> dp(t + 1);
    auto value = [&](int i,int j) -> int {
        return dp[j] - j / v[i] * w[i];
    };
    
    for(int i = 0;i < n;i++) {
        //同余分组
        for(int mod = 0;mod <= min(t,v[i] - 1);mod++) {
            //单调队列优化
            
            deque<int> dq;
            //预先窗口：
            //在后序遍历中，预先加入维护前cnt[i]个节点指标
            for(int j = t - mod,c = 1;j >= 0 && c <= cnt[i];j -= v[i],c++) {
                while(!dq.empty() && value(i,dq.back()) <= value(i,j)) {
                    dq.pop_back();
                }
                dq.push_back(j);
            }
                
            //倒序r在左，l在右
            for(int l = t - mod,r = l - v[i] * cnt[i];l >= 0;l -= v[i],r -= v[i]) {
                //加入对于左端点背包大小需要的最后一个位置 -> r + 维护队列单调性
                if(r >= 0) {
                    while(!dq.empty() && value(i,dq.back()) <= value(i,r)) {
                        dq.pop_back();
                    }
                    dq.push_back(r);
                } 
                
                //更新背包
                dp[l] = value(i,dq.front()) + l / v[i] * w[i];
                
                //去除窗口中旧数据
                if(dq.front() == l) dq.pop_front();
            }
        }
    }
    cout << dp[t];
    return;
}
signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(0);
    int T = 1;
    //cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```

## 评价：

## 题目：

## 思路：
### 1. 暴力的树形dp - 重点对于`状态设计`的思考角度：

#### 基础思考 (树形dp) ： 如何再树上结果中找到线性递归，或者说如何找到在子节点返回所需的子树信息来整合出父节点所需返回的子树信息 ？？

##### 一. 3维状态设计 - dfs(i,  j , k);

而 3D 状态巧妙地引入了**孩子索引维度 `j`**，彻底化解了多叉分支的混乱：

1. **第一维 `i`（当前位置）**：我们在以 `i` 为根的子树里。
    
2. **第二维 `j`（进展维度 / 孩子指针）**：我们**正在处理** `i` 的前 `j` 个孩子（即从第 0 个孩子到第 `j-1` 个孩子）。
    
3. **第三维 `k`（资源维度 / 容量分配）**：当前这个分支中，总共可以分配的容量（名额）是 `k`。
    

> **核心思想**：原本“一瞬间要分配给所有孩子”的复杂多叉组合问题，被降维成了**“一个一个孩子来做抉择”的序列化流水线**。

##### 二、 算法思维的本质：子树展开与流水线分配

我们可以把 `dfs(i, j, k)` 想象成这样一个场景： 你手里拿着 `k` 个名额，站在节点 `i` 面前，他的孩子排成了一排（第 0 个，第 1 个，……，第 `j-1` 个）。

你不需要一次性决定所有孩子分多少，你只需要做**最后一步决策**：

- **眼前的抉择**：看一眼当前要处理的最后一个孩子 `v`（即 `g[i][j-1]`）。
    
- **资源划分（枚举 `s`）**：我到底要分给这个孩子 `v` 及其子孙 **`s`** 个名额呢？还是分配 **`0`** 个名额？
    
- **状态转移的递推感**：
    
    - 如果分给子孙 `s` 个名额，那么这 `s` 个名额的内部规划交由 `dfs(v, g[v].size(), s)` 去解决。
        
    - 剩下的 `k - s` 个名额，回过头去交由前面的兄弟子孙 `dfs(i, j - 1, k - s)` 去解决。
	    
	- 但是这里注意：
	 我在分派给第j个孩子s个名额时，我要保证时上限时$s \le k - 1$，因为题目要求这里需要先选完父位置，才选择子位置；所以我们再分配名额时，一定要留下一个名额；
	
这就是**序列化分组背包**的精髓：**通过引入“孩子后缀/前缀”的概念，把并行的树形分支变成了串行的选择过程。**



#### 这里强调一个细节设计：

##### 1. 森林变树：虚拟根节点的“容器”哲学

- **思想**：现实中的多棵树（森林）是无法直接从一个单一入口 `dfs` 的。
    
- **强化**：通过人为构造一个学分为 0 的虚拟根节点 `0`，把所有孤立的连通分量“一网打尽”挂在它下面。这告诉我们：**在面对图论或树形 DP 时，当入口不唯一、结构不统一，引入一个虚拟的超级源点（Virtual Root）是降维打击的常用套路。**
    

##### 2. 容量守恒与“+1”的精妙契合

- **思想**：题目要求选 `M` 门课。
    
- **强化**：因为虚拟根节点 `0` 自己要白白占用 1 个名额（学分为 0），所以我们的总容量宏观上必须是 `M + 1`。这培养了我们对“资源边界与附加虚拟节点开销”的敏感度。
    

##### 3. 正权值带来的“宽容边界”

- **思想**：在 `j == 0 || k == 1` 时直接返回 `val[i]` 的宽容处理。
    
- **强化**：这让我们意识到，算法的最优性不仅取决于严密的数学逻辑，还取决于**题目性质的约束**。因为学分全为正数，且有 `max` 的竞争机制，局部的“超额分配”在全局最优解的筛选下会被自然淘汰。

#### 3维dp代码：
```c++
//3维树上01背包
void solve() { 
    int n, m;
    cin >> n >> m;
    m++; // 加上虚拟根节点 0，总容量为 m + 1
    
    vector<int> val(n + 1, 0); 
    vector<vector<int>> g(n + 1);
    for(int i = 1; i <= n; i++) {
        int k, s;
        cin >> k >> s;
        val[i] = s;
        g[k].push_back(i);
    }
    
    //上面都是建图的过程，注意这里再解决树上背包建图中，通过邻接表的方式来建图最为合适；
    
    //dp(memo)用于记忆化储存 - 递归剪枝；
    vector<vector<vector<int>>> dp(n + 1);
    for(int i = 0; i <= n; i++) {
        int sz = g[i].size();
        dp[i].resize(sz + 1);
        for(int j = 0; j <= sz; j++) {
            dp[i][j].resize(m + 1, -1);
        }
    }
	
    auto dfs = [&](this auto&& dfs, int i, int j, int k) -> int {
        if(k == 0) return 0;
		
        //这里在j == 0的时候逻辑还做了简化，//如上:细节设计 - 宽容边界
        //因为这里K == 1是合法的，
        //但是如果k >= 2时，这是子树规模已经是 < k ，但是我这里同样也return val[i]
        //逻辑相当于：在题目保证至少有1解的情况下，我多出的次数完全可以给别的子树从而产生一个更高的分数
        if(j == 0 || k == 1) return val[i];

        //记忆化
        if(dp[i][j][k] != -1) return dp[i][j][k];
    
        int ans = -1;
        int v = g[i][j - 1];
        for(int s = 0; s < k; s++) {
            ans = max(ans, dfs(i, j - 1, k - s) + dfs(v, g[v].size(), s));
        }
        
        return dp[i][j][k] = ans;
    };

    cout << dfs(0, g[0].size(), m) << endl;
}
```


### 2. dfn序列优化

这种利用 **DFN 序（深度优先搜索时间戳 / 欧拉序思想）** 将树形结构展平成线性数组，进而把复杂的 3D 树形背包降维成 **2D 线性背包**的思路，是一种非常高级且优雅的算法优化技巧。

下面为你详细拆解这个算法的核心思想、推导过程以及最终的代码实现。

#### 一、 算法核心思想：降维打击

在前面我们讨论的 3D 树形背包中，难点在于需要用一个维度去动态维护“当前处理到第几个孩子”。

而 **DFN 序线性化优化** 的核心哲学是：

> **利用 DFS 预处理，把一棵复杂的、多叉分支的树，变成一条线性的数组。在先序遍历（Pre-order）下，任何一棵子树在数组中都必然对应着一段连续的区间：`[dfn[x], dfn[x] + sz[x] - 1]`。**

既然子树变成了一条连续的区间，那么原本复杂的树上背包，就完全变成了类似于 **0-1 背包的线性区间决策问题**。

#### 二、 状态定义与核心推导

##### 1. 状态定义

设 **`dp[i][j]`** 表示：从 DFN 序第 `1` 个节点开始到`n + 1`，总共分配 **`j` 个容量（名额）** 时，能够获得的最大学分。


##### 2. 两种核心决策（状态转移）

###### 一、 核心基石：先序 DFN 序的“区间连续性”

当我们对一棵树进行先序遍历（Pre-order DFS）时，会给每个节点编一个号（DFN 序）。这里有一个极其重要的数学性质：

> **以任意节点 $u$ 为根的整棵子树，在 DFN 序的数组中，必然占据一段连续的闭区间：`[dfn[u], dfn[u] + sz[u] - 1]`。**
> 
> - 其中 `sz[u]` 是以 $u$ 为根的子树节点总数（包含 $u$ 自己）。
>     

这意味着，原本在图论中散落各处的树形结构，被我们“拉直”成了一条线性数组。在这条数组上：

- 索引 `i` 代表当前正考虑的节点。
    
- 它的整棵子树的所有后代，紧紧挨在它的后面，一直延伸到 `i + sz[i] - 1`。
    
- 越过整棵子树之后的**第一个“局外人”**（即它的兄弟节点或叔叔节点），其 DFN 序坐标正好就是 **`i + sz[i]`**。
    

###### 二、 拆解两个核心状态转移的“底层逻辑”

有了“子树对应连续区间”的概念，我们在 DFN 序数组上从右向左（自底向上）倒推时，针对当前处于 DFN 序第 `i` 个位置的节点，只有两个非此即彼的宏观决策：

**决策 1：不选当前节点（`no_choose`**

代码实现：

C++

```
int no_choose = dp[i + sz[i]][j];
```

- **道理是什么？**
    
    - 如果你决定**放弃**当前节点（课程）`i`，根据树的依赖关系（不学先修课，后面的课全白搭），这整棵以 `i` 为根的子树的所有后代课程你也**全都没有资格选了**。
        
    - 既然整棵子树都被“连根拔起”放弃了，那么你在 DFN 序数组上，就必须**直接跳过这整棵子树的所有节点**。
        
    - 这整棵子树占了多大地方？占了 `sz[i]` 个位置。
        
    - 所以，跳过它之后，你接下来能做决策的“下一个有效节点”的位置，就是 **`i + sz[i]`**。
        
    - 因为你没有选这个节点，所以容量 `j` 没有任何消耗，直接继承 `dp[i + sz[i]][j]`。
        

**决策 2：选择当前节点（`choose`）**

代码实现：

C++

```
int choose = 0;
if (j >= 1) {
    choose = dp[i + 1][j - 1] + dfn_val[i];
}
```

- **道理是什么？**
    
    - 如果你决定**选择**当前节点 `i`：
        
        1. 你获得当前节点的学分：`dfn_val[i]`。
            
        2. 你消耗了 **1** 个容量名额，剩余容量变成 **`j - 1`**。
            
    - 选了当前节点之后，下一步我们该考虑谁？
        
    - 在先序 DFN 序中，排在当前节点 `i` 紧后面的，就是它的**第一个直接孩子**（如果它有孩子的话）或者下一个平级节点。
        
    - 因此，我们无缝衔接地转移到 DFN 序的下一个位置 **`i + 1`**，去处理剩余的容量 `j - 1`。
        
    - 状态写出来就是：`dp[i + 1][j - 1] + dfn_val[i]`。

补充理解：
我这里每一步所维护处理来的值如（`dp[i][j]`）表示的含义：
	
- 对于第 `1` 个节点开始到`n + 1`，总共分配 `j` 个容量
	
- 如果当前的存在一个虚拟的根节点，也就是说我只考虑dfn序从`1`到`n + 1`（外围）的范围，从而去取出一个合法的最大得分
	
- 这里合法的意思就是”先选完父位置，才选择子位置“从而取选取一个最大的合法得分；
	
- 我想象在每个递推范围中，我在该范围假设都存在一个虚拟根节点，从该位置出发的最大合理选择；在递推过程中在由于dfn序倒序遍历，会发现我每个范围都需要依赖一个更靠近底层的合法范围，也就是dfn序`i`更大的合法范围；
	
- 每一个都是在做一个合法选择，我只需要倒序遍历到根节点（dfn序为`1`的节点），而在每个范围都去遍历”该范围的不同状态也就是背包大小“即可； 

###### 总结下来状态转移：

当我们来到 DFN 序上的第 `i` 个节点时，我们只有两个大方向的选择：

1. **不选当前节点（连同它的整棵子树全部放弃）**：
    
    - 如果不选当前节点 `i`，那么它整棵子树里的所有后代节点也全不能选。
        
    - 在 DFN 序上，这意味着我们**直接跳过这整棵子树**，跳跃的步数正好是 `sz[i]`。
        
    - 状态转移：`dp[i][j] = dp[i + sz[i]][j]`
        
2. **选择当前节点**：
    
    - 如果选择了当前节点 `i`，它会消耗 **1** 个容量，并带来 `dfn_val[i]` 的学分。
        
    - 接下来我们可以继续处理它的下一个紧邻节点（即 DFN 序的下一个位置 `i + 1`），剩余容量变为 `j - 1`。
        
    - 状态转移：`dp[i][j] = dp[i + 1][j - 1] + dfn_val[i]`
        
3. **综合转移方程**：
    $$\text{dp}[i][j] = \max(\text{dp}[i + \text{sz}[i]][j], \text{dp}[i + 1][j - 1] + \text{dfn\_val}[i])$$



#### 代码 - dfn序列转化成递推式（二维优化）：
```c++
void solve1() {
    int n,m;
    cin >> n >> m;
    vector<vector<int>> graph(n + 1);
    vector<int> val(n + 1);
    for(int i = 1;i <= n;i++) {
        int k,s;
        cin >> k >> s;
        val[i] = s;
        graph[k].push_back(i);
    } 
    
    vector<int> dfn(n + 1);
    vector<int> sz(n + 2);
    vector<int> dfn_val(n + 2);
    int idx = 0;
    auto dfs = [&](this auto&& dfs,int x) -> int {
        int node = ++idx;
        dfn[x] = node;
        dfn_val[node] = val[x];
        int cnt = 1;
        for(auto& next : graph[x]) cnt += dfs(next);  
        sz[node] = cnt;
        return cnt;
    };
    dfs(0);
    
    vector<vector<int>> dp(n + 3,vector<int>(m + 1));
    for(int i = n + 1;i >= 2;i--) {
        for(int j = 1;j <= m;j++) {
            // no choose :
            dp[i][j] = max(dp[i][j],dp[i + sz[i]][j]);
            // choose :
            dp[i][j] = max(dp[i][j],dp[i + 1][j - 1] + dfn_val[i]);
        }
    }
    cout << dp[2][m] << endl;
    return;
}
```
