## 例题1 ：树形dp - 状态设计

## 相关链接 ：

- 题目链接：[968. 监控二叉树 - 力扣（LeetCode）](https://leetcode.cn/problems/binary-tree-cameras/)

## 思路 ：

### 理清正确的 3 个状态（本题标准树形 DP）

> 对于节点 `x`
1. `s0`：x 没有摄像头 → 除去该点以下的子树全覆盖
2. `s1`：x 没有有摄像头，但**被儿子监控** → 子树全覆盖
3. `s2`：x 有摄像头，但由**自己监控** → 子树全覆盖

### 状态设计 ：

**在以`x`点作为根节点的子树（`x`的状态暂时不考虑)全覆盖做到最小使用个数的状态**；

### 但是这里就存在一些疑问：


- #### problem1 : 每个节点我是否还需要去储存可以做到最小使用个数的状态作为子树递归状态返回，或者说每个节点是否需要左右孩子的多个满足状态？
	
- 这里我先说结论 : 不会存在一个节点上有多个满足状态，对于每一步递推是一个局部选择贪心的过程；
	
	
	
- #### problem2 : 为什么“局部贪心”能省去多状态返回？
	
	这背后的核心原因在于**贪心策略的正确性（最优子结构与贪心选择性质）**：
	
1. **绝不在叶子节点上放摄像头**： 如果我们把摄像头放在叶子节点上，它只能覆盖自己和父节点；而如果把摄像头放在叶子节点的**父节点**上，它不仅能覆盖父节点、叶子节点，还能覆盖父节点的另一侧。因此，自底向上看，永远优先把摄像头往上提一层（放在父节点）是更优或等价的选择。
    
2. **状态驱动的唯一决策**：
    
    - 当左右孩子向父节点返回状态时：
        
        - 如果孩子的状态是 `0`（未覆盖），说明孩子急需被救，父节点**别无选择**，必须在当前节点放一个摄像头（返回 `2`，`ans++`）。这是一个**强制性**的局部最优决策，不需要比较多种候选方案。
            
        - 如果孩子的状态都是 `1`（已覆盖），说明子树目前很安全，当前节点**绝对不应该**放摄像头（放了就是浪费），此时当前节点应该保持为 `0`（未覆盖）向上返回，等更高层的父节点来救它。
            
        - 如果孩子有摄像头（`2`），当前节点就被顺便覆盖了，返回 `1`。


## 代码展示：

```c++
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int minCameraCover(TreeNode* root) {
        int ans = 0;
        auto dfs = [&](this auto&& dfs,TreeNode* x) -> int {
            if(!x) return 1;
            auto l_vis = dfs(x->left);
            auto r_vis = dfs(x->right);
            if(l_vis == 0 || r_vis == 0) {
                ans++;
                return 2;
            }
            else {
                if(l_vis == 1 && r_vis == 1) return 0;
                else return 1;
            }
        };
        int vis = dfs(root);
        if(!vis) ans++;
        return ans;
    }
};
```




# 例题2 ：树形dp + 同余处理

## 相关链接 ：

- 题目链接：[E-小红加边_牛客周赛 Round 169](https://ac.nowcoder.com/acm/contest/143199/E)


## 题目大意

给定一棵 $n$ 个节点的树。现在需要在树上添加一条无向边，使其变成一棵包含唯一环的“基环树”，并且要求这个唯一的环的边数是 $3$ 的倍数。 求加边的方案数（即有多少对无序节点满足条件）。



## 问题转化

在树上任意两个节点 $u$ 和 $v$ 之间添加一条边，由于树本身是连通且无环的，加边后必定会形成一个环。 该环的长度由两部分组成：

1. 原树中 $u$ 到 $v$ 的最短路径长度，即 $\text{dist}(u, v)$。
    
2. 我们新加的这一条边，长度为 $1$。
    

因此，形成的环的长度为 $\text{dist}(u, v) + 1$。 题目要求环长是 $3$ 的倍数，即：

$$(\text{dist}(u, v) + 1) \equiv 0 \pmod 3$$
变形后得到：

$$\text{dist}(u, v) \equiv 2 \pmod 3$$

**核心结论：** 这道题的本质就是求树上有多少对无序节点 $(u, v)$，使得它们在原树中的距离模 $3$ 余 $2$。



## 思路 ： 

处理树上路径统计问题，最常用的方法是点分治或者树形 DP。因为我们只关心路径长度模 $3$ 的结果，状态空间极小，所以 **$O(n)$ 的树形 DP 是最优解**。


### 1. 状态设计

设 `dp[u][0]`, `dp[u][1]`, `dp[u][2]` 分别表示： 在以 $u$ 为根的子树中，到节点 $u$ 的距离模 $3$ 余数为 $0, 1, 2$ 的节点个数。


### 2. 初始状态

对于遍历到的每一个节点 $u$，它到它自己的距离是 $0$，所以： `dp[u][0] = 1`，其他均为 $0$。


### 3. 状态转移与答案统计（计数统计中类似于“维护左，枚举右”思想）

在 DFS 遍历的过程中，假设我们正在节点 $u$，并且准备合并它的一个子节点 $v$ 的信息。 一条合法的跨越 $u$ 的路径，是由“$u$ 之前遍历过的子树中的某个点”经过 $u$，走到“当前子树 $v$ 中的某个点”构成的。

设左半部分路径长度为 $x$，右半部分路径（在 $v$ 子树中到 $v$ 的距离）为 $y$。 整条路径的长度为：$x + y + 1$ （加 $1$ 是因为 $u$ 到 $v$ 有一条边）。 我们需要 $(x + y + 1) \equiv 2 \pmod 3$，即 $x + y \equiv 1 \pmod 3$。

满足组合的 $(x \bmod 3, y \bmod 3)$ 有三种情况：

- $(0, 1) \implies$ `dp[u][0] * dp[v][1]`
    
- $(1, 0) \implies$ `dp[u][1] * dp[v][0]`
    
- $(2, 2) \implies$ `dp[u][2] * dp[v][2]`

我们在遍历每个子节点 $v$ 时，**先根据乘法原理累加答案**，**再将 $v$ 的子树信息合并到 $u$ 上**。 合并时，因为从 $v$ 走到 $u$ 多了一条边，所以 $v$ 子树中所有点的距离都会 $+1$：

- `dp[u][1] += dp[v][0]`
    
- `dp[u][2] += dp[v][1]`
    
- `dp[u][0] += dp[v][2]`

_注意：必须先统计答案，后合并状态。这能确保路径的两个端点一定来自 $u$ 的不同分支，避免同子树内部的路径被错误计算。_

## 代码展示：
```c++
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define endl '\n'
#define ctz __builtin_ctzll         // 二进制表示中末尾连续0的个数

const int mod = 1e9 + 7;

void solve() {
    int n;
    cin >> n;

    vector<vector<int>> graph(n + 1);
    for (int i = 1; i < n; ++i) {
        int u, v;
        cin >> u >> v;
        graph[u].push_back(v);
        graph[v].push_back(u);
    }

    int ans = 0;
    vector<vector<int>> dp(n + 1, vector<int>(3, 0));

    auto dfs = [&](auto&& self, int u, int fa) -> void {
        dp[u][0] = 1; 
        for (int v : graph[u]) {
            if (v == fa) continue;
            self(self,v, u);
            
            ans += dp[u][0] * dp[v][1];
            ans += dp[u][1] * dp[v][0];
            ans += dp[u][2] * dp[v][2];

            dp[u][1] += dp[v][0];
            dp[u][2] += dp[v][1];
            dp[u][0] += dp[v][2];
        }
    };
    dfs(dfs,1, 0);

    cout << ans << endl;
    return;
}

    }

}
```
