## 评价 ：

**其实kmp只是一层外壳，真正内核的是`next`的数组的含义和功能**


## 背景：KMP 算法解决什么问题？ 

- **字符串匹配（Substr / Pattern Matching）**：在一个主串 `haystack`（长度为 $N$）中查找另一个子串 `needle`（长度为 $M$）第一次出现的位置。
    
- **暴力解法的痛点**：暴力匹配在每次失配时，主串指针 `x` 会回退，子串指针 `y` 归零，时间复杂度为 $O(N \times M)$。
    
- **KMP 的优势**：利用已经匹配过的信息，**主串指针 `x` 永不回退**，通过维护一个 `next` 数组让子串指针 `y` 进行智能回跳，将时间复杂度优化到 **$O(N + M)$**。


## 二、 核心概念：`next` 数组

- **定义**：`next[i]` 表示 `needle` 字符串中，以 `i - 1` 结尾的子串中，**最长相等的前缀和后缀的长度**（或者说是指针应该回跳的位置）。
	
- 基于`next`数组这个特殊的定义，还可以去解决一个字符串的最长前缀回文串问题 - [214. 最短回文串 - 力扣（LeetCode）](https://leetcode.cn/problems/shortest-palindrome/)（解决方式 ：kmp , 马拉车）
    
- **在你的模板中的具体规定**：
    
    - `next[0] = -1`：标志位，表示当 `y` 回退到开头仍不匹配时，主串指针 `x` 应该右移。
        
    - `next[1] = 0`：第一个字符之前没有真前缀/后缀，规定为 0。
        
    - `next[i]`：当处于位置 `i` 失配时，`y` 可以直接跳到 `next[i]` 的位置继续比较。


## `KMP`算法的实现流程 ：

### 阶段 1：生成 `next` 数组（自我匹配） - `kmp`算法的精华

`next` 数组的构建本质上是 **`needle` 自己和自己做匹配**。

- **核心逻辑**：
    
    - 用变量 `cn` 表示当前待比较的前缀位置（同时也是最长相等前后缀的长度）。
        
    - 遍历字符串，若当前字符 `str[i - 1] == str[cn]`，说明前后缀可以延长，`next[i++] = ++cn`。
        
    - 若不等，则让 `cn` 通过 `next` 数组回跳（`cn = next[cn]`），直到找到相等的字符或 `cn == -1`。

### 阶段 2：KMP 匹配过程  -  kmp比对只是基于`next`数组上的双指针而已

- **双指针移动**：
    
    - `x` 指向主串 `haystack`，`y` 指向模式串 `needle`。
        
- **分支处理**：
    
    - **匹配成功**：`haystack[x] == needle[y]`（或遇到 `y == -1` 的保护位），`x++`, `y++`。
        
    - **匹配失败**：`y = next[y]`。子串指针回跳，主串指针 `x` **保持不动**。
        
- **终止条件**：`y == m`（匹配成功，返回起始下标 `x - y`）或 `x == n`（主串遍历完仍未找到）。


## 关键代码模板 ：

**`next`数组建立  -  (有点动态规划的思想)**

```
vector<int> next(m + 1);
auto nxt = [&](const string& s) -> void {
	int cn = 0;
	for(int i = 0;i <= m;i++) {
		if(!i) next[i] = -1;
		else if(i == 1) next[i] = 0;
		else {
			while(cn != -1 && s[cn] != s[i - 1]) cn = next[cn];
			next[i] = ++cn;
		}
	}
};
nxt(needle);
```

kmp比对 - 本质 “双指针” （一个目标字符串，一个用于在上面查找比对的字符串）

```c++
int x = 0,y = 0;
while(x < n && y < m) {
	if(haystack[x] == needle[y]) {
		x++;
		y++;
	}
	else if(y == 0) {
		x++;
	}
	else {
		y = next[y];
	}
}
return (y == m ? x - y : -1);
```
