## 例题 1 ：模板题 

### 题目链接：

- 题目链接： [28. 找出字符串中第一个匹配项的下标](https://leetcode.cn/problems/find-the-index-of-the-first-occurrence-in-a-string/)

### 代码展示 ：
```c++
class Solution {
public:
    int strStr(string haystack, string needle) {
        int n = haystack.size(),m = needle.size();
        
        // create next数组
        vector<int> next(m);
        auto nxt = [&](const string& s) -> void {
            int cn = 0;
            for(int i = 0;i < m;i++) {
                if(!i) next[i] = -1;
                else if(i == 1) next[i] = 0;
                else {
                    while(cn != -1 && s[cn] != s[i - 1]) cn = next[cn];
                    next[i] = ++cn;
                }
            }
        };
        nxt(needle);

        //kmp
        int x = 0,y = 0;
        while(x < n && y < m) {
            if(haystack[x] == needle[y]) {
                x++;
                y++;
            }
            else if(y == 0) {
                x++;
            }
            else {
                y = next[y];
            }
        }
        return (y == m ? x - y : -1);
    }
};
```


## 例题 2 ：(启发性题目)  最长前缀回文串

### 相关链接 ：

- 题目链接 ： [214. 最短回文串](https://leetcode.cn/problems/shortest-palindrome/)


### 核心解题思路

1. **转化为最长回文前缀问题**：
    
    - 题目要求在字符串 `s` **前面**添加字符使其变成回文串。
        
    - 这实际上等价于：**找出 `s` 从头开始的最长回文前缀**。
        
    - 假设最长回文前缀的长度为 `len`，那么 `s` 后面剩余的部分（即从下标 `len` 开始到结尾的子串）就是无法配对的部分。我们只需要把这部分**翻转**，然后拼接到 `s` 的最前面即可。


### 巧妙利用 KMP 的 `next` 数组：

- **怎么高效求出“最长回文前缀”？** 我们可以构造一个新字符串： `t = s + "#" + reverse(s)` - 这样我们就把题目转换成了找到一个“**最长相等前后缀长度**”的问题，所以我们可以基于`next`数组的定义轻松完成；
    
- **构造新字符串的巧妙定义** ：其中 `"#"` 是一个分隔符，防止前后字符产生混淆。
    
- 对新字符串 `t` 求其 KMP 的 `next` 数组。
    
- **核心结论**：`t` 整个字符串的最后一个字符所对应的 `next` 值，就是 `s` 的**最长回文前缀的长度**！


## 代码展示 ：
`
```c++
class Solution {
public:
    // kmp方式
    string shortestPalindrome(string s) {
	    //构造
        string rev_s = s;
        reverse(rev_s.begin(), rev_s.end());
        string t = s + "#" + rev_s;
        int m = t.size(); 
		
		//next
	    vector<int> next(m + 1);
        auto nxt = [&]() -> void {
            int cn = 0;
            for(int i = 0; i <= m; i++) {
                if(!i) next[i] = -1;
                else if(i == 1) next[i] = 0;
                else {
                    while(cn != -1 && t[cn] != t[i - 1]) cn = next[cn];
                    next[i] = ++cn;
                }
            }
        };
        nxt();
		
        int len = next[m];
        string add_part = s.substr(len);
        reverse(add_part.begin(), add_part.end());
        //
        return add_part + s;
    }
};
```
