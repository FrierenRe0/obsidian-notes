# isprime - 判断质数

```c++
auto isprime = [&](int x) -> bool {
	int c = x;
	for(int i = 2;i * i <= c;i++) {
		if(c % i == 0) return false;
	}
	return x >= 2;
}
```


## 1.为啥这里如果存在一个（0，x ^ 1/2】的情况就表示是合数？

**思考如果对于一个数来说，他的质因数数量一定是>=2,对于合数来说，其质因数数量 > 2,这里一定存在一质因数对 a  *  b == x（ 定：a <= b && a != 1 );**

**我们假设 a ≤ b, 那么一定有： $a * b ≥ a * a$**
**也就是：$x ≥ a^2$**
**移项得：$x^{\frac12} ≥ a$**

**所以，则我们只要看是否存在一个 $(0 \ ,\ x^{\frac12}]$ 的情况，有则为合数，否则为质数；

# 分解质因数

```c++
//这里数组返回，得到的是该数的所有质因数（去重 -> 种类集合）
//附加：(题目具体情况具体分析)
//如 ：还需要记录对应质因数的个数，返回数组中存pair<int,int> (质因数，对应个数) 即可；
auto get_prime = [&](int x) -> vector<int> {
    vector<int> p;
    int c = x;
  
    for (int i = 2; i * i <= c; i++) 
    {
        if(c % i == 0) 
        {
	        p.push_back(i); 
	        while (c % i == 0) c /= i;
	    }
    }
    if (c > 1) p.push_back(c);
    return p;
};
```
