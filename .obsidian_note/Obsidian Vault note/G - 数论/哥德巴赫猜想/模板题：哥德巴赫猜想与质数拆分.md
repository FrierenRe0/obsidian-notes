## 1. 问题模型

**题目常见形式**：给定一个正整数 $n$，要求将其拆分为最少数量的质数之和，输出最少的质数个数。如果无法拆分（如 $n=1$），输出 $-1$。

## 2. 核心数学定理（基石）

解决此问题的核心在于数论中的两个重要猜想/定理：

- **强哥德巴赫猜想**：任何大于 2 的**偶数**都可以写成**两个质数**的和。
    
    - _公式表达_：$n = p_1 + p_2$ （其中 $n \% 2 == 0$ 且 $n > 2$，$p_1, p_2$ 为质数）。
        
- **弱哥德巴赫猜想**（已被完全证明）：任何大于 5 的**奇数**都可以写成**三个质数**的和。
    
    - _公式表达_：$n = p_1 + p_2 + p_3$ （其中 $n \% 2 \neq 0$ 且 $n > 5$，$p_1, p_2, p_3$ 为质数）。
        

> **补充常识**：在所有质数中，**2 是唯一的偶质数**，其余所有质数均为奇数。

## 3. 分类讨论与核心逻辑

基于上述定理，对于任意正整数 $n$，我们可以展开如下的分类讨论：

### 情况 ①：$n = 1$

- **结论**：无法拆分，输出 `-1`。
    
- **原因**：因为最小的质数是 2，1 本身不是质数，也无法由任何质数相加得到。


### 情况 ②：$n$ 本身是质数

- **结论**：不需要拆分，输出 `1`。


### 情况 ③：$n$ 是大于 2 的偶数

- **结论**：根据_强哥德巴赫猜想_，必然可以拆分为 2 个质数，输出 `2`。


### 情况 ④：$n$ 是大于 3 的奇数

由于 $n$ 不是质数（已在情况 ② 排除），因此答案至少为 2。我们优先尝试能不能拆成 **2 个质数**。


- **数学推理**：
    
    要让两个数相加等于奇数，必须是 **一奇 + 一偶**。
    
    因为唯一的偶质数是 **2**，所以如果 $n$ 能拆成两个质数，其中一个**必须是 2**，另一个则必须是 $n - 2$。
    
- **判断逻辑**：
    
    - 如果 `isprime(n - 2)` 为真，说明 $n = 2 + (n - 2)$ 成立，输出 `2`。
        
    - 如果 `isprime(n - 2)` 为假，说明无论如何都不可能拆成 2 个质数了。根据_弱哥德巴赫猜想_，它一定能拆成 **3 个质数**（可以通过先拿走一个质数 3，让剩下的偶数 `n - 3` 拆成 2 个质数来实现），输出 `3`。
    

## 4. 算法状态机（速查表）

```
                  [ 输入整数 n ]
                        │
         ┌──────────────┴──────────────┐
       n = 1                        n > 1
         │                             │
    ┌────┴────┐               ┌────────┴────────┐
   输出 -1                n 是质数           n 不是质数
                              │                 │
                           输出 1        ┌──────┴──────┐
                                      n 为偶数      n 为奇数
                                         │             │
                                       输出 2    ┌─────┴─────┐
                                            n-2是质数    n-2不是质数
                                                 │           │
                                               输出 2      输出 3
```

## 代码如下：

```c++
#include <bits/stdc++.h>
using namespace std;
#define int long long
const int mod = 1e9 + 7;
const int N = 3e5 + 7;

//isprime  -->  判断质因数模板
bool isprime(int x) {
	for(int i = 2;i * i <= x;i++) {
		if(x % i == 0) return false;
	}
	return x >= 2;
}

void solve() {
    int n;
    cin >> n;
    
    //哥德巴赫猜想思路
    if(n == 1) {
        cout << -1 << endl;
    }
    else if(isprime(n)) {
        cout << 1 << endl;
    }
    else if(n % 2 == 0) {
        cout << 2 << endl;
    }
    else {
        if(isprime(n - 2)) cout << 2 << endl;
        else cout << 3 << endl;
    }
    
    return;
}
signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(0);
    int T = 1;
    cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```
