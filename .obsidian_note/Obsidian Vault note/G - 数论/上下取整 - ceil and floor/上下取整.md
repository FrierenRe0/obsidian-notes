**注意，代码中的 `\` 是向零取整，接下来是对于无论分子，字母是否为正负对于除法结果在数学意义上的上下取整**
## 对于浮点数的上下取整可以直接调用函数接口 ： 
- `ceil` -> 向上取整；
- `floor` -> 向下取整；

## 对于给定为整数的分子，分母来对结果进行上下取整，这里我给出对应的代码模板：
### 向下取整，往数轴更小方向取最近整数 ：等价于 `floor(x)`

```c++
//向下取整
int floor_div(int a,int b) {
    int q = a / b;
    int r = a % b;
    if(r != 0 && (a < 0) != (b < 0)) q--;
    return q;
}
```

### 向上取整，往数轴更大方向取最近整数 ：等价于 `ceil(x)`

```c++
//向上取整
int ceil_div(int a,int b) {
    int q = a / b;
    int r = a % b;
    if(r != 0 && ((a < 0)) == (b < 0)) q++;  
    return q;                         
}
```
