
**对于子集问题在二进制上面的处理，其实本质的思想类似于“状态压缩”**

## 核心思想：集合与二进制的压缩映射

在计算机中，我们可以用一个整数的二进制位来表示一个包含非负整数的集合 $S$：

- **规则**：二进制从低到高第 $i$ 位为 `1` 表示 $i$ **在**集合中，为 `0` 表示 $i$ **不在**集合中。
    
- **例子**：集合 $\{0, 2, 3\}$ 可以压缩成 $2^0 + 2^2 + 2^3 = 13$，对应的二进制为 `1101`。
    
- **优势**：利用计算机位运算**并行计算**的特点，可以把原本复杂的集合操作（如求交集、判断子集）加速到 $O(1)$。
    

## 一、 集合与集合的运算

| **集合论概念**     | **数学符号**        | **位运算写法**                    | **原理简述**                           |
| ------------- | --------------- | ---------------------------- | ---------------------------------- |
| **交集**        | $A \cap B$      | a & b                        | 两个集合都有的元素（两边都为 1 的位）               |
| **并集**        | $A \cup B$      | a \| b                       | 合并两个集合的所有元素（任一边为 1 的位）             |
| **对称差 / 异或**  | $A \triangle B$ | a ^ b                        | 存在于其中一个集合、但不同时存在的元素                |
| **差集 / 补集**   | $A \setminus B$ | a & ~b                       | 属于 $A$ 且不属于 $B$ 的元素（去掉 $B$ 中也有的元素） |
| **包含于（判断子集）** | $A \subseteq B$ | (a & b) == a 或 (a & ~b) == 0 | 检查 $A$ 的所有元素是否都在 $B$ 中             |

## 二、 元素与集合的单点操作

针对单个元素 $i$ 和集合 $s$ 的日常操作：

1. **查询元素**：判断 $i$ 是否在集合 $s$ 中
    
    - 写法：`(s >> i) & 1` 或 `(s & (1 << i)) != 0`
        
2. **添加元素**：将 $i$ 加入集合 $s$
    
    - 写法：`s | (1 << i)`
        
3. **删除元素**：将 $i$ 从集合 $s$ 中移除
    
    - 写法：`s & ~(1 << i)`
        

## 三、 常用底层技巧与内置函数

在写代码时，许多语言（如 C++, Python, Go）提供了高效的内置函数或经典按位技巧：

- **集合大小（统计 1 的个数）**：
    
    - 计算集合中有多少个元素，对应 C++ 中的 `__builtin_popcount(s)`（`long long` 用 `__builtin_popcountll`）。
        
- **Lowbit（最低位的 1 / 最小元素）**：
    
    - `s & -s`：能够直接提取出二进制中最低位的那个 `1` 及其后面的所有 `0`（常用于树状数组或遍历集合中的元素）。
        
- **获取集合的最大/最小元素**：
    
    - **最小元素**：可以通过计算尾零个数（如 C++ 的 `__builtin_ctz`）或直接利用 `Lowbit`。
        
    - **最大元素**：可以通过计算二进制最高位（如 C++ 的 `__lg(s)`）。
    
- **计算元素二进制的长度**： `bit_width(1ULL * x)（c++20）`或 `64 - __builtin_clzll(x)（c++14）` ;
## 四、 高阶技巧：高效遍历子集

### 全局子集遍历 

C++

```
int sub = s;
for(;sub >= 0;sub--) {
	// 处理当前子集 sub 的逻辑
	
}
```


### 遍历不含空集子集

在做状压 DP 或子集枚举时，如果直接用暴力减一会遇到很多“不是当前集合子集”的无效状态。

**压缩版二进制减法**技巧，可以做到**只遍历 $s$ 的所有合法子集**，中间不做任何无效跳转：

C++

```
int sub =  s;
while(sub) {
	// 处理当前子集 sub 的逻辑
	
	sub = (sub - 1) & s;// 核心：减一后通过按位与过滤掉不属于 s 的比特位，和树状数组的区间传递的本质差不多，都是对于最低位的处理
}
```


### 遍历包含空集子集

C++

```
// 
int sub = s;
do {
    // 处理当前子集 sub 的逻辑
    
    sub = (sub - 1) & s; // 核心：减一后通过按位与过滤掉不属于 s 的比特位，和树状数组的区间传递的本质差不多，都是对于最低位的处理
} while (sub != s);
```
