## 前置知识：

- 阶乘前缀和 ： $fac[i]$ 表示为 i 的阶乘  (注意这里0的阶乘为1)
- 逆元 (费马小定理) ：  再模运算中，$a^{-1} \ mod \ p$ 等价于  $a^{p - 2} \ mod \ p$ ，同时这里a与p互质
- 快速幂 ：在计算逆元 $a^{p - 2}$ 时，需要使用上快速幂

## 对于 $C_n^k$ 以及 $A_n^k$ 的相关代码如下：
```c++
const int N = ;

const int mod = 1e9 + 7;
const int MOD = 998244353;
int fac[N], inv[N];

int ksm(int n, int m){
    int res = 1;
    n %= mod;
    while(m){
        if(m & 1){
            res = res * n % mod;
        }
        n = n * n % mod;
        m = m >> 1;
    }
    return res;
}

int init = [](){
    fac[0] = inv[0] = 1;
    for(int i = 1; i < N; i++){
        fac[i] = fac[i - 1] * i % mod;
        inv[i] = ksm(fac[i], mod - 2);
    }
    return 0;
}();

int C(int n, int m){
    return fac[n] * inv[n - m] % mod * inv[m] % mod;
}
int A(int n, int m){
    return fac[n] * inv[m] % mod;
}
```
