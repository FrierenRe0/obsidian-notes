## 题目大意

给定一个长度为 $n$ 的整数数组 `nums`（其中元素在 $0 \sim 2^{15}-1$ 范围内）。我们需要对 `nums` 进行重新排列得到排列 `perm`，并构造一个长度为 15 的数组 `power`：

- `power[i]` 表示 `perm` 的前 $j$ 个元素中，第 $(14 - i)$ 位（二进制最高位到最低位）**全部为 1** 的最大前缀长度 $j$。
    

要求返回能使 `power` 数组 **字典序最大** 的 `power` 数组。

## 解题思路：位优先级与高位贪心

### 1. 字典序优先与位精度的等价性

由于目标是让 `power` 数组的字典序最大：

- 我们必须优先保证 `power[0]`（对应第 14 位，即二进制最高位）的前缀长度尽可能长；
    
- 在满足 `power[0]` 最大的前提下，再争取让 `power[1]`（第 13 位）尽可能长；
    
- 依此类推……
    

在二进制中，高位的权重具有绝对压制性：

$$2^{14} > 2^{13} + 2^{12} + \dots + 2^0$$

因此，如果在保留某些二进制位的掩码（Mask）时存在多种选择，**按位与（`AND`）结果数值更大的方案，必然保留了尽可能高的位置位（1）**。这使得我们可以直接将“找字典序最优位组合”转化为简单的“比较整数数值大小”。

### 2. 核心算法流程（掩码收缩 + 贪心）

我们维护一个表示当前所有连续全 1 位集合的掩码 `mask`（初始为全 1，即 `0b111111111111111 = 32767`），以及当前排列中已填入的元素个数 `level`。

在每轮循环中：

1. **完全匹配批量处理（批量无损加入）**：
    
    遍历剩余数字，若存在数字 $x$ 满足 `(x & mask) == mask`，说明 $x$ 包含当前 `mask` 要求的全部 1。将所有这样的数字**一次性全部放进排列前缀**。因为它们完全包含 `mask` 的 1，所以放进去**绝对不会打断**任何位的连续全 1 状态。
    
2. **寻找最佳退化数（高位优先放弃）**：
    
    若没有数能完美匹配 `mask`，说明当前 `mask` 中的全 1 状态无法继续维持，必须放弃一部分 1。我们寻找使得 `(x & mask)` **数值最大**的数字 `choose`（记 `best = choose & mask`）。
    
3. **记录被打断的位**：
    
    计算本次被迫放弃的二进制位：`removed = mask & (~best)`。对于 `removed` 中为 1 的第 $i$ 位，说明第 $i$ 位的前缀全 1 状态到此截止，记录答案：
    $$\text{ans}[14 - i] = \text{level}$$
1. **更新状态与缩小掩码**：
    
    将选出的 1 个 `choose` 放入排列（`cnt[choose]--`），更新掩码 `mask = best`，并递增 `level`。
    

由于二进制最多只有 15 位，每轮若无法批量清空，`mask` 至少会减少 1 个置位，因此 `while` 循环**最多只会执行 15 次**。

## C++ 代码实现

C++

```
const int N = 1 << 15;   // 2^15 = 32768
class Solution {
public:
    vector<int> largestPower(vector<int>& nums) {
        // 题目中间变量保存
        vector<int> velqoranim = nums;
        
        int n = nums.size();
        vector<int> cnt(N, 0);
        for (int x : nums) cnt[x]++;
        
        int level = 0;
        int mask = N - 1;       // 初始掩码：0b111111111111111
        vector<int> ans(15, n); // 初始化默认为 n（若某一位全程全 1，则前缀长为 n）
        
        while (level < n) {
            int best = -1, choose = -1;
            
            for (int i = 0; i < N; i++) {
                if (!cnt[i]) continue;
                
                int val = i & mask;
                // 情况 1：数值 i 完全包含了当前 mask 中的所有 1
                if (val == mask) {
                    level += cnt[i]; // 批量放置，不打断任何全 1 状态
                    cnt[i] = 0;
                } 
                // 情况 2：寻找能保留更高位 1 的数值
                else if (val > best) {
                    best = val;
                    choose = i;
                }
            }
            
            // 边界防越界处理：所有数字均已排入前缀，直接结束
            if (level == n) break;
            
            // 计算在此步被迫放弃的 1
            int removed = mask & (~best);
            for (int i = 0; i < 15; i++) {
                if ((removed >> i) & 1) {
                    ans[14 - i] = level; // 记录该位终止时的连续全 1 前缀长度
                }
            }
            
            // 消耗 1 个选中的最佳数字并缩小掩码
            cnt[choose]--;
            mask = best;
            level++;
        }
        
        return ans;
    }
};
```

## 复杂度分析

- **时间复杂度**：$\mathcal{O}(B \cdot 2^B)$，其中 $B = 15$ 为二进制位数。
    
    - 外层 `while` 循环最多执行 $B = 15$ 次。
        
    - 内层 `for` 循环遍历频次数组大小 $2^{15} = 32768$。
        
    - 总运算量约为 $15 \times 32768 \approx 4.9 \times 10^5$ 次，耗时在 $1\sim 2\text{ ms}$ 级别，可轻松通过。
        
- **空间复杂度**：$\mathcal{O}(2^B)$。
    
    - 频次统计数组 `cnt` 的大小为 $2^{15} = 32768$。
        

## 避坑指南 / 细节处理

1. **为什么需要 `if (level == n) break;`？**
    
    在最后一轮时，如果剩余的所有数字均在 `val == mask` 的分支被批量处理完，此时 `level` 会直接达到 `n`，但没有数字去触发 `else if (val > best)`，导致 `choose` 保持初始值 `-1`。如果不提前退出，后续执行 `cnt[choose]--` 时会引发 **`cnt[-1]` 数组下界越界崩溃**。
	
2. **消耗 1 个 `choose` 逐个推进 -> 这样写的好处在哪？** 
	
	 当数字无法完美包含 `mask` 时，我们必须使用一个数高位贪心出最大的结果同时来缩小掩码。每次只能放 1 个数并进入下一轮重新评估全局最优选数，不能不能一次性把 `cnt[choose]` 全部清空，但是我如果先**消耗 1 个 `choose` 逐个推进**，在下一层中我在 $val = mask$  中就会批量将上一层`choose`该元素 和 按位与结果等价的其他元素 都批量添加计算，删除，我这样处理是一个包含关系，代码更加简洁。
