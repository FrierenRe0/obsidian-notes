
虽然结构体命名为 `BIT`，但这段代码**并不是树状数组**（传统树状数组无法直接维护任意区间最值），而是一棵**非递归线段树（又称 ZKW 线段树）**，用于支持 **0-indexed（下标 `0` 到 `n - 1`）的单点修改与区间最大值查询**。

### 一、底层数组 `w` 的空间布局

这棵树用一维数组 `w` 存储一棵自底向上的完全二叉树（实际使用下标 `1` 到 `2n - 1`）：

- **叶子节点（原始数组）**：存放在 **`w[n]` 到 `w[2n - 1]`**。原始下标 `pos`（$0 \le \text{pos} < n$）在树中的位置就是 `pos + n`。
    
- **非叶子节点（区间最大值）**：存放在 **`w[1]` 到 `w[n - 1]`**，其中 `w[1]` 是整棵树的根节点。
    
- **父子与兄弟关系（利用二进制位运算性质）**：
    
    - 节点 `p` 的**父节点**是 **`p / 2`**。
        
    - 节点 `p` 的**亲兄弟**是 **`p ^ 1`**（偶数 `+1` 变成右兄弟，奇数 `-1` 变成左兄弟）。


### 单点修改
#### 1. `modify(int pos, int val)`：单点修改（自底向上更新）

C++
```
void add(int pos, int val) {
    for (w[pos += n] = val; pos > 1; pos /= 2) {
        w[pos / 2] = max(w[pos], w[pos ^ 1]);
    }
}
```


1. `w[pos += n] = val`：先定位到对应的叶子节点 `pos + n`，将其值改为 `val`。
    
2. `pos /= 2`：一路向上爬到根节点 `1` 为止。
    
3. `w[pos / 2] = max(w[pos], w[pos ^ 1])`：每一层都用当前节点 `pos` 和它的兄弟节点 `pos ^ 1` 的最大值，去刷新它们的父节点 `pos / 2`。时间复杂度 $O(\log n)$。


### 区间查询
#### 2. `rangeMax(int l, int r)`：区间最大值（左闭右开 `[l, r)` 夹逼）

C++
```
int rangeMax(int l, int r) {
    r++; // 将闭区间 [l, r] 转化为左闭右开区间 [l, r + 1)
    int res = -1e18;
    for (l += n, r += n; l < r; l /= 2, r /= 2) {
        if (l % 2) res = max(res, w[l++]);
        if (r % 2) res = max(res, w[--r]);
    }
    return res;
}
```

核心思想是让左右指针 `l` 和 `r` 从叶子层一起往上爬；如果某个边界**无法凑成完整的父节点**，就先把它单独统计进 `res`，再向内收缩边界：

- **`if (l % 2) res = max(res, w[l++]);`（处理左边界）**
    
    - 若 `l` 是**奇数**，说明 `l` 是父节点的**右孩子**。它的父节点会包含左兄弟 `l - 1`（超出了查询范围），不能直接往上跳！因此必须**单独统计 `w[l]`**，然后 `l++` 右移进入下一棵完整子树。
        
    - 若 `l` 是**偶数**，说明 `l` 是左孩子，它的右兄弟 `l + 1` 也在区间内，直接放心 `l /= 2` 跳到父节点即可。
        
- **`if (r % 2) res = max(res, w[--r]);`（处理右边界）**
    
    - 因为 `[l, r)` 是**右开区间**，真正的最右端元素其实是 `r - 1`：
        
    - 若 `r` 是**奇数**，说明 `r - 1` 是偶数（左孩子），它的右兄弟 `r` 不在查询区间内，不能直接往上跳！因此先 `--r` 退回到合法的右端点，**单独统计 `w[r]`**。
        
    - 若 `r` 是**偶数**，说明 `r - 1` 是奇数（右孩子），整个父节点都完全落在区间内，直接 `r /= 2` 跳到父节点即可。


## ZKW代码模板：

C++
```
struct ZKW {
    vector<int> w;
    int n;
    BIT(int n) : n(n), w(2 * n + 1) {}

    void add(int pos, int val) {
        for (w[pos += n] = val; pos > 1; pos /= 2) {
            w[pos / 2] = max(w[pos], w[pos ^ 1]);
        }
    }

    int rangeMax(int l, int r) {
        r++; // 使用开区间实现
        int res = -1e18;
        for (l += n, r += n; l < r; l /= 2, r /= 2) {
            if (l % 2) res = max(res, w[l++]);
            if (r % 2) res = max(res, w[--r]);
        }
        return res;
    }
};
```
