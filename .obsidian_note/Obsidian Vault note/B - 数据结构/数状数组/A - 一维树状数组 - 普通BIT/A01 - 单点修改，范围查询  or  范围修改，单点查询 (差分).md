
## 这里我引入一个树状数组算法的核心本质：

对于可以通过树状数组来处理的问题，本质都是基于`单点更新，区间查询`这一核心思想；

无论是对于后面提到的 `范围修改，范围查询` 还是 `范围增加，范围查询`，其本质都是在利用`单点更新，区间（前缀）查询`这一核心目的；

### 四、 总结对比表，场景对比

| 需求场景                    | 需要几个树状数组            | 树状数组里存的是什么？ | 树状数组的 `query` 操作代表什么？ |
| ----------------------- | ------------------- | ----------- | --------------------- |
| **单点修改 + 区间查询** (最基础)   | **1 个**             | 原数组 A[i]    | 真正的区间求和               |
| **区间修改 + 单点查询**         | **1 个**             | 差分数组 D[i]   | **原数组某个位置的单点值** A[x]  |
| **区间修改 + 区间查询** (你刚才问的) | **2 个** (`a` 和 `b`) | 差分数组及其衍生项   | 用于数学推导组合出区间总和         |

所以，通过数学上的**差分思想**，同一个树状数组可以瞬间摇身一变，用来做**单点查询**！

## 结构体封装写法

### 单点修改，范围查询

```c++
struct BIT {
    vector<int> w;
    int n;
    BIT(int n) : n(n), w(n + 1) {}
    
    //单点修改
    void add(int x, int v) {
        for (; x <= n; x += x & -x) {
            w[x] += v;
        }
    }
    
    //区间查询
    int rangeAsk(int l, int r) { 
        auto ask = [&](int x) {
            int ans = 0;
            for (; x > 0 ; x -= x & -x) {
                ans += w[x];
            }
            return ans;
        };
        return ask(r) - ask(l - 1);
    }
};
```



### 范围修改，单点查询

```c++
struct BIT {
    vector<int> w;
    int n;
    BIT(int n) : n(n), w(n + 1) {}
    
    //范围修改
    void rangeAdd(int l,int r,int v) {
		auto add = [&](int x, int v) -> void {
	        for (; x <= n; x += x & -x) {
	            w[x] += v;
	        }
	    };
	    add(l , v) , add(r + 1 , -v); 
    }
    
    //单查询
    
    int ask(int x) {
        int ans = 0;
        for (; x > 0 ; x -= x & -x) {
            ans += w[x];
        }
        return ans;
    };
};
```
