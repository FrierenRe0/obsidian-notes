### 一、 核心数学推导：如何用差分表达前缀和？

假设原数组为 $A = [A_1, A_2, \dots, A_n]$。

我们引入**差分数组 $d$**，其定义为：

$$d_1 = A_1$$

$$d_i = A_i - A_{i-1} \quad (\text{对于 } i > 1)$$

由此可得，原数组中任意元素 $A_i$ 可以表示为差分数组的前缀和：

$$A_i = \sum_{j=1}^{i} d_j$$

现在，我们的目标是求原数组的前缀和 $S(x)$（即前 $x$ 个元素的总和）：

$$S(x) = \sum_{i=1}^{x} A_i$$

将 $A_i = \sum_{j=1}^{i} d_j$ 代入上式：

$$S(x) = \sum_{i=1}^{x} \left( \sum_{j=1}^{i} d_j \right)$$

#### 1. 交换求和顺序（核心一步）

在双重求和中，差分项 $d_j$ 到底被累加了多少次？

- 当 $j = 1$ 时，$d_1$ 会出现在 $A_1, A_2, \dots, A_x$ 中，共出现 $x$ 次。
    
- 当 $j = 2$ 时，$d_2$ 会出现在 $A_2, A_3, \dots, A_x$ 中，共出现 $x - 1$ 次。
    
- $\dots$
    
- 当 $j = x$ 时，$d_x$ 只出现在 $A_x$ 中，共出现 $1$ 次。
    

因此，对于任意的 $d_j$（其中 $1 \le j \le x$），它总共出现了 **$(x - j + 1)$** 次。我们可以把求和符号展开：

$$S(x) = \sum_{j=1}^{x} d_j \cdot (x - j + 1)$$

#### 2. 拆分乘法项

将 $(x - j + 1)$ 展开为 $(x + 1) - j$：

$$S(x) = \sum_{j=1}^{x} d_j \cdot \left[ (x + 1) - j \right]$$

根据乘法分配律，将其拆为两个独立的求和项：

$$S(x) = \sum_{j=1}^{x} \left[ d_j \cdot (x + 1) - j \cdot d_j \right]$$

利用求和的线性性质，把与 $x$ 相关的常数项提出来：

$$S(x) = (x + 1) \cdot \sum_{j=1}^{x} d_j - \sum_{j=1}^{x} (j \cdot d_j)$$

### 二、 为什么需要两个树状数组（`a` 和 `b`）？

通过上面的严密推导，我们得到了计算前缀和 $S(x)$ 的终极公式：

$$S(x) = (x + 1) \cdot \underbrace{\sum_{j=1}^{x} d_j}_{\text{部分 1}} - \underbrace{\sum_{j=1}^{x} (j \cdot d_j)}_{\text{部分 2}}$$

观察这个公式，为了在 $O(\log n)$ 时间内求出 $S(x)$，我们只需要维护两个前缀和：

1. **树状数组 `a`**：用来维护差分数组 $d_j$ 的前缀和，即 $\sum_{j=1}^{x} d_j$。
    
2. **树状数组 `b`**：用来维护带权差分数组 $j \cdot d_j$ 的前缀和，即 $\sum_{j=1}^{x} (j \cdot d_j)$。
    

这就是为什么代码中需要定义 `vector<int> a, b;` 的根本原因。

### 三、 代码实现与逻辑对应

#### 1. 区间修改 (`rangeAdd`)

当我们在原数组的区间 $[l, r]$ 内统一加上一个值 $val$ 时，对差分数组 $d$ 的影响是：

- 在位置 $l$ 处：$d_l \mathrel{+}= val$
    
- 在位置 $r + 1$ 处：$d_{r+1} \mathrel{-}= val$
    

对应到树状数组的单点更新中，`add(pos, val)` ，函数同时更新了 `a` 和 `b`：

C++

```
auto add = [&](int pos, int val) {
    for (int i = pos; i <= n; i += i & -i) {
        a[i] += val;           // 维护差分数组 d[i] 的前缀和
        b[i] += pos * val;     // 维护 j * d[j] 的前缀和 (此时 j = pos)
    }
};
```

我们对 $l$ 执行 `add(l, val)`，对 $r+1$ 执行 `add(r + 1, -val)`，完美实现了对于`a`,`b`两个树状数组 $O(\log n)$ 的区间修改，达到`区间增加`的目的。

#### 2. 区间查询 (`rangeAsk`)

要求区间 $[l, r]$ 的和，根据前缀和相减的原理：

$$\text{RangeSum}(l, r) = S(r) - S(l - 1)$$

代码中的 `sum(x)` 函数完美契合了我们前面推导的公式：

C++

```
auto sum = [&](int x) {
    int ans = 0;
    for (int i = x; i; i -= i & -i) {
        // 对应公式：(x + 1) * sum(a) - sum(b)
        ans += (x + 1) * a[i] - b[i];
    }
    return ans;
};
```

在树状数组求和的循环过程中，利用分配律把 `(x + 1) * a[i] - b[i]` 直接累加，省去了分别查询两个树状数组的额外开销，代码极其精妙。最后返回 `sum(r) - sum(l - 1)` 即可得到区间 $[l, r]$ 的真实总和。


### 完整结构体封装写法：

```c++
struct BIT {
    vector<int> a, b;
    int n;

    BIT(int n) : n(n), a(n + 1), b(n + 1) {}
    
    //范围增加
    void rangeAdd(int l, int r, int val) { 
        auto add = [&](int pos, int val) {
            for (int i = pos; i <= n; i += i & -i) {
                a[i] += val;
                b[i] += pos * val;
            }
        };
        add(l, val), add(r + 1, -val);
    }
    
    //范围查询
    int rangeAsk(int l, int r) { 
        auto sum = [&](int x) {
            int ans = 0;
            for (int i = x; i; i -= i & -i) {
                ans += (x + 1) * a[i] - b[i];
            }
            return ans;
        };
        return sum(r) - sum(l - 1);
    }
};
```
