## 字典树（Trie）算法深度解析

字典树（Trie）是一种用于高效存储和检索字符串数据集的树形数据结构。它的核心思想是“空间换时间”**与**“前缀共享”。与直接将所有字符串存入数组相比，字典树能将具有相同前缀的字符串合并存储，从而极大地压缩空间并加速查询。



### 1. 底层存储设计 (Vector + 下标)

传统的树结构通常使用指针（`new Node()`）来连接父子节点，但这在频繁申请内存时会带来巨大的性能开销，且容易引发内存泄漏或缓存不命中。

你的代码采用了一种极具现代 C++ 风格的**动态数组（`vector`）连续存储方案**：

- **节点结构**：每个 `Node` 包含一个长为 $A$（字符集大小）的整型数组 `to`。`to[v]` 存储的不是指针，而是**子节点在 `vector` 中的下标**。
    
- **根节点锚定**：树的起点永远是 `tr[0]`。初始化时通过 `tr.assign(1, Node())` 放入唯一的根节点。
    
- **动态开点**：当插入新字符时，直接使用 `tr.emplace_back()` 在数组尾部追加一个空节点，并将新节点的下标（即扩容前的 `tr.size()`）赋给父节点的 `to` 数组。这种按需分配的方式不仅省内存，还能保证内存地址相对连续，极大提高了 CPU 缓存命中率 , 防止`MLE`。





### 2. 双计数器模型 (`ps` 与 `ed`)

这是该模板支持“复杂统计”与“动态删除”的灵魂所在。每个节点维护了两个整型状态：

- **`ps` (Prefix Size / Pass)**：**经过该节点的字符串数量**。只要有一个字符串的前缀包含当前节点，该节点的 `ps` 就会加 1。
    
- **`ed` (End Count)**：**以该节点为终点的字符串数量**。只有当一个完整的单词在这里结束时，`ed` 才会加 1。

通过这两个计数器，我们可以衍生出非常强大的功能。





### 3. 核心操作原理解析

- **插入字符串 (`insert`)**：
    
    从根节点出发，将字符串的每个字符转化为索引 $v$。如果走向 $v$ 的路不通（`!tr[u].to[v]`），就“铺路”（动态开点）。沿途走过的每一个节点，其 `ps` 都增加 1；走到终点时，终点节点的 `ed` 增加 1。时间复杂度为 $O(\vert{}S\vert{})$（$\vert{}S\vert{}$ 为字符串长度）。
    
-   **逻辑删除  (`erase`)**：
    
    Trie 树的物理删除极其麻烦且低效。你的代码完美实现了“逻辑删除”：先遍历验证字符串是否存在，若存在，则将终点的 `ed` 减 1，并把来时路径上所有节点的 `ps` 减 1。
    
    **精妙之处**：物理节点依然保留在 `vector` 中，但只要它的 `ps` 归零，在后续的查询或遍历中，程序就会认为这是一个“已废弃”的死胡同，达到了完美删除的效果。
    
- **高效查询 (`ask` & `askPre`)**：
    
    - **查精确匹配**：顺着字符走，最后返回终点的 `ed`（如果是 0 说明只作为前缀存在过，没作为独立单词插入过）。
        
    - **查前缀匹配**：顺着字符走，最后返回终点的 `ps`（直观反映了当前还有多少个有效单词包含该前缀）。




### 4. 深度优先搜索与状态剪枝 (`askMax`)

你的 `askMax` 函数展示了如何在字典树上进行图论搜索，这通常用于解决“最长词链”、“最大匹配深度”等进阶问题。

代码中使用了 **C++23 的 `this auto&& dfs` 语法**，使得 Lambda 递归更加简洁。最值得注意的细节是：

C++

```
if (v && tr[v].ps) dfs(v, d);
```

这里的 `tr[v].ps` 就是一个**极其高效的剪枝条件**。因为我们支持删除操作（`erase`），树中可能存在大量的“废弃分支”（空间开了，但单词全被删了）。通过判断 `ps > 0`，DFS 能够精准避开所有的“鬼节点”，只在包含有效单词的路径上探索。





### 5. 泛型与高可扩展性

模板头部 `template <int A = 26, char F = 'a'>` 设计得非常通用：

- 若处理纯小写字母，默认参数即可。
    
- 若处理 `0-9` 的数字串，只需改成 `Trie<10, '0'>`。
    
- 若处理所有 ASCII 可见字符，改成 `Trie<128, 0>` 即可。



**总结**：
这棵字典树不仅仅是一个“存储字符串的工具”，它实际上是一个**前缀状态机**。通过静态下标模拟指针、动态内存分配、以及 `ps/ed` 双轨计数，它在时空复杂度上都达到了非常优异的平衡，是一个可以直接带入高级算法考场的成熟模板。



### 字典树代码模板如下：


```c++
/*
用途：定长连续字符集 Trie，支持插入、删除、单词/前缀计数与最长前缀词链。
用法：Trie<26, 'a'>；节点转移、编号和计数使用 int。
性能：默认使用宏展开后的 int；若大规模数据因此超时或超空间，可将纯下标、状态或计数局部改为 i32。
*/
template <int A = 26, char F = 'a'> struct Trie {

    struct Node {
        array<int, A> to{};
        int deep = 0;
        int ps = 0;
        int ed = 0;
    };

    vector<Node> tr;
	
    Trie() {
        clear();
    }

    //清空初始化
    void clear() {
        tr.assign(1, Node());
    }

    //获取下标
    int id(char c) const {
        int x = c - F;
        assert(0 <= x && x < A);
        return x;
    }

    //插入操作
    void insert(const string& s) {
        int cur = 0;
        //这里对于cur = 0,表示的是现在字典树中插入了多少条字符串
        ++tr[cur].ps;
        
        for (char c : s) {
            int idx = id(c);
            if (!tr[cur].to[idx]) {
                int next = tr.size();
                tr.emplace_back();//在数组tr的最后添加一个 空Node
	            tr[next].deep = tr[cur].deep + 1;
            }
            u = tr[u].to[v];
            ++tr[u].ps;
        }
        ++tr[u].ed;
    }

    //有效删除操作;
    bool erase(const string& s) {
        int u = 0;
        //这里用vector存储 -> 保证了做的是有效删除字符串，无效的情况下直接false;
	    //初始化：0
	    vector<int> p{0};
        
        for (char c : s) {
            int v = id(c);
            
            //如果找不到了，false;
            if (!tr[u].to[v]) return false;
            
            u = tr[u].to[v];
            p.push_back(u);
        }
	    //这里位置没有一个字符串再该处结尾
        if (!tr[u].ed) return false;
        
        //否则就是有效字符串
        --tr[u].ed;
        for (int v : p) --tr[v].ps;
        return true;
    }

    //询问是否存在该字符串(也不一定时字符串，也可以时其他形式);
    int ask(const string& s) const {
        int u = 0;
        for (char c : s) {
            int v = id(c);
            if (!tr[u].to[v]) return 0;
            u = tr[u].to[v];
        }
        return tr[u].ed;
    }

    //询问是否存在当前情况下有多少个以该字符串为前缀的字符串；
    int askPre(const string& s) const {
        int u = 0;
        for (char c : s) {
            int v = id(c);
            if (!tr[u].to[v]) return 0;
            u = tr[u].to[v];
        }
        return tr[u].ps;
    }

    //询问单词集的最大集合规模(大小)；
    int askMax() const {
        int r = 0;
        auto dfs = [&](this auto&& dfs, int u, int d) -> void {
            d += tr[u].ed > 0;
            for (auto& v : tr[u].to) {
                if(v && tr[v].ps) dfs(v, d); 
                //空间上是开了，但是如果是需要计数的背景下，还要看这里这里还有没有ps(也就是被经过); 
            }
            r = max(r, d);
        };
        dfs(0, 0);
        return r;
    }
};
```
