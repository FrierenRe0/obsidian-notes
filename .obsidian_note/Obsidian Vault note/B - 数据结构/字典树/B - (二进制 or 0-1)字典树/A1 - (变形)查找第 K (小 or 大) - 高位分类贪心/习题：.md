[Problem - F2 - Codeforces](https://codeforces.com/contest/2267/problem/F2)
### 评价：字典树优化 + 优先队列(最小堆)的多线路合并

## 一、 题目背景与核心挑战

在许多涉及**异或（XOR）极值与数组演化**的算法题中，核心操作通常是：对数组中的每个元素，寻找它与其余元素异或产生的值，并按照某种规则（如从小到大排序、选取特定排名等）更新数组，最后支持多次对某一时间步状态的查询。

- **朴素解法的瓶颈**：如果对每个元素都与其它所有元素进行两两异或，单轮复杂度高达 $O(N^2)$。当数据范围较大（如 $N \le 2 \times 10^5$）时，暴力计算必定超时。
    
- **优化方向**：必须借助 **0-1 字典树（Trie）** 将单次异或极值查询优化到 $O(\log V)$，并利用**小根堆（优先队列）多路归并**来避免全量生成 $N^2$ 个异或值。
    

## 二、 核心数据结构设计：带有 `ps` 的 0-1 Trie

为了支持“查询与某个数异或第 $K$ 小的值”，普通的 Trie 是不够的。我们需要在节点中引入一个核心统计字段：**`ps`（Prefix Size / 子树大小）**。

C++

```
struct Node {
    array<int,2> son{}; // son[0] 和 son[1] 分别代表二进制位 0 和 1 的子节点编号
    int ps = 0;         // 记录经过该节点的数字总个数（即子树承载量）
    int end = 0;        // 标记位
};
```

### 1. 插入操作 (`insert`)

将数组中的数字从高位（第 29 位）到低位（第 0 位）逐位插入 Trie 中：

- 根节点及沿途经过的所有子节点，其 `ps` 均自增 `1`。
    
- 若对应的分支不存在，则动态开辟新节点。


### 2. 高位贪心与第 $K$ 小查询 (`find`)

给定一个目标数 `x`（可以是不在 Trie 中的任意整数），求它与 Trie 中所有数字异或结果**第 $K$ 小**的值：

- **贪心策略**：异或要想小，高位必须优先为 `0`（即优先走与 `x` 当前位相同的分支）。
    
- **区间跳转机制**：
    
    - 计算期望分支（能让 `bit`位 异或结果为 0 的分支）中的数字总数 `tr[left_child].ps`。
		
	- 如果该分支没有，则只能走相反的分支路径（`b ^ 1`) 。
	    
	- 否则，如果 `tr[left_child].ps >= k`，说明第 $K$ 小的异或值就藏在该分支内，直接进入。
        
    - 如果数量不够，说明需要把该分支的数字全部跳过，执行 `k -= tr[left_child].ps`，然后强行转向相反的分支。


## 三、 小根堆多路归并：高效提取前 $2N$ 个极小异或值

对于数组中的每个元素，它和所有元素异或会产生一个单调递增的候选序列。有 $n$ 个元素就有 $n$ 条这样的序列。

在 `change` 演化函数中：

1. **多路归并初始化**：将所有元素初始的第 2 小异或值（第 1 小是自己异或自己，值为 0）放入小根堆 `pq` 中。
    
2. **按需提取**：循环 $2n$ 次，每次从堆顶弹出当前全局最小的异或值，并利用 `cnt[i]++` 将该元素的指针向后推一位，把它的下一个较小异或值压入堆中。
    
3. **更新数组**：将提取出的紧凑极小值按规则（如间隔采样）更新回数组 `a` 中。



## 四、 整体演化与查询处理

1. **模拟演化**：利用 `while(now)` 循环不断执行 `change(a)`，直到数组达到稳定状态（极差 `now` 变为 0）。
    
2. **记忆化记录**：用哈希表 `mp` 记录每一个时间步 `c` 对应的数组极差。
    
3. **高效查询**：面对 $Q$ 次查询，直接通过 $O(1)$ 的哈希表读取对应时间步的答案并输出。



```c++
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define endl '\n'
#define ctz __builtin_ctzll         // 二进制表示中末尾连续0的个数
#define clz __builtin_clzll         // 二进驻表示中先导0的个数
#define count1 __builtin_popcountll // 二进制表示中1的个数
const int mod = 1e9 + 7;
const int MOD = 998244353;
const int N = 2e5 + 7;

struct Node {
    array<int,2> son{};
    int ps = 0; 
    int end = 0;
};

vector<int> a;

void solve() { 
    int n, q;
    cin >> n >> q;
    unordered_map<int, int> mp;
    a.resize(n);
    int mx = -1, mi = INT_MAX; 
    for(auto& x : a) {
        cin >> x;
        mx = max(mx, x);
        mi = min(mi, x);
    }
    
    auto change = [&](vector<int>& a) -> void {
        vector<Node> tr;
        tr.emplace_back(); 

        auto insert = [&](int x) -> void {
            int v = 0;
            tr[v].ps++;
            for(int i = 29; i >= 0; i--) {
                int b = (x >> i) & 1;
                if(!tr[v].son[b]) {
                    tr[v].son[b] = tr.size();
                    tr.emplace_back();
                }
                v = tr[v].son[b];
                tr[v].ps++;
            }
        };
    
        // 字典树 -> find ：查询与 x 异或第 k 小的值
        // 找到在{i，j}中和 a[i] 异或第 k 小的元素(这里保证一定存在第k小的值)，return 该第k小的值
        auto find = [&](int x, int k) -> int {
            int v = 0;
            int res = 0;
            for(int i = 29; i >= 0; i--) {
                int b = (x >> i) & 1;
                int left_child = tr[v].son[b];

                if(left_child && tr[left_child].ps >= k) {
                    v = left_child;
                    res += (1 << i) * b;
                } else {
                    if(left_child) k -= tr[left_child].ps;
                    v = tr[v].son[b ^ 1];
                    res += (1 << i) * (b ^ 1);
                }
            }
            return res ^ x;
        };

        for(int i = 0; i < n; i++) {
            insert(a[i]);
        }

        // 这里用 pair 存储 {xor值, 元素索引}
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<>> pq;
        vector<int> cnt(n, 2); 

        for(int i = 0; i < n; i++) {
	        // 这里k == 2目的: 找到在 j == i 除外中，最小的异或值;
            pq.push({find(a[i], 2), i}); 
        }

        vector<int> u;
        for(int c = 1; c <= 2 * n; c++) {
            auto [val, i] = pq.top();
            pq.pop();
            u.push_back(val);
            cnt[i]++;
            if(cnt[i] > n) continue;
            pq.push({find(a[i], cnt[i]), i});
        }

        for(int i = 0; i < n; i++) {
            a[i] = u[i * 2];
        }
    };

    //记录：
    int now = mx - mi;
    int c = 0;
    while(now) {
        mp[c++] = now;
        change(a);
        now = a[n - 1] - a[0];
    }


    // question : 
    while(q--) {
        int t;
        cin >> t;
        if(!mp.count(t)) cout << 0 << endl; 
        else cout << mp[t] << endl;
    }

    return;
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(0);
    int T = 1;
    cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```
