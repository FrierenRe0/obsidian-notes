## 概述：

**这是对于字典树查找`异或极值`的问题 : 这里就不在是暴力将0-1二进制串贪心化的查询到底，而是要合理的分类贪心**；



## 一、核心应用场景

当题目中涉及以下特征时，通常可以考虑 0-1 Trie：

1. **异或操作（XOR）**：异或满足二进制独立性，且 $0 \oplus 0 = 0, 1 \oplus 0 = 1$。
    
2. **极值或排名查询**：如“求与某个数异或最小/最大的是谁”、“求与某个数异或第 $K$ 小的值”。
    
3. **数据规模较大**：暴力两两计算是 $O(N^2)$，Trie 可以将单次查询优化到 $O(\log V)$（$V$ 为数值上限，通常二进制位数为 30 位左右）。




## 二、数据结构设计：为什么需要 `ps` (子树大小)?

普通的 Trie 只能判断“是否存在某个前缀”。为了支持“第 $K$ 小”的排名查询，每个节点必须记录一个附加信息，总的来说就是：
 - 查询 异或极值 问题 ：我们在贪心遍历时，只需要看相同构造路径的存在性，不需要`ps`来记录以当前前缀开头的数字的数量；
 - 查询 与`x`异或的第k个极值 问题 ：我们在贪心时，因为不仅需要看相同构造路径的存在性，还需要看路径上的以当前前缀开头的数字的数量（ps）从而分类讨论；

- **`son[2]`**：指向子节点的指针（`son[0]` 代表该位是 0，`son[1]` 代表该位是 1）。
    
- **`ps` (Prefix Size / Subtree Size)**：**核心字段**。记录有多少个数字的二进制前缀经过了当前节点。
    -  它的本质是一个计数器，代表**以当前前缀开头的数字总共有多少个**。




## 三、核心操作一：插入 (`insert`)

将数字以二进制形式（从高位到低位，例如从第 29 位到第 0 位）逐位插入 Trie 中。

- **逻辑**：
    
    1. 从根节点开始，每向下走一层，当前节点的 `ps++`。
        
    2. 如果对应的子节点不存在，则动态新建一个节点。
        
    3. 重复直到最低位，完成一个数字的注册。




## 四、核心操作二：高位贪心与第 $K$ 小查询 (`find`) —— **思维最精髓处**

给定一个目标数 `x`，要在 Trie 中找到与它异或结果**第 $K$ 小**的值。

### 1. 贪心策略（高位优先）

- **异或的性质**：要想让两个数异或的结果尽可能小，**高位应当尽可能为 0**。
    
- 如果 $x$ 的当前位是 `b`（0 或 1）：
    
    - **优先走相同位**：如果 Trie 中存在与 $x$ 当前位相同的分支（即异或后该位为 0），我们应当优先走这条路，因为高位能出 0 就绝不出 1。
        
    - **备选相反位**：如果相同位的数字不够 $k$ 个，我们才被迫转向相反的分支（异或后该位为 1）。


### 2. 利用 `ps` 进行区间跳转（类似线段树/权值树状数组的二分思想）

在每一位 $i$ 的分叉口：

1. 计算优先分支（能让异或结果为 0 的分支）中包含的数字总数：`int left_child = tr[v].son[b];`
    
2. **分类讨论**：
    
    - **情况 A（数量足够）**：若 `left_child` 存在且 `tr[left_child].ps >= k`。
        
        - 说明第 $K$ 小的异或值就藏在这个分支里。
            
        - **动作**：直接跳入该子节点，当前位的异或贡献为 `0`（即 `res += (1 << i) * b` 对应匹配成功）。
            
    - **情况 B（数量不足）**：若 `left_child` 的数字个数小于 $k$（或者根本不存在）。
        
        - 说明光靠这个分支的数字凑不够 $K$ 个，我们需要把这个分支的所有数字全部“跳过”。
            
        - **动作**：
            
            - 更新剩余排名：`k -= tr[left_child].ps`（减去左边不够的这部分人数）。
                
            - 强行转向相反的分支：`v = tr[v].son[b ^ 1]`。
                
            - 当前位的异或贡献为 `1`（即 `res += (1 << i) * (b ^ 1)`）



## 代码展示：

```c++
struct Node { 
	array<int,2> son{};
	int ps = 0;
	int end = 0;
};

void solve() {
	int n,cin >> n;
	vector<int> a(n);
	for(auto& x : a) cin >> x; // 这里的数据范围在 0 <= x < 2^30; 
	
	vector<Node> tr;
	tr.emplace_back();
	
	
	//字典树 insert插入板子；
	auto insert = [&](int x) -> void {
		int cur = 0;
		tr[cur].ps++;
        for(int i = 29; i >= 0; i--) {
            int b = (x >> i) & 1;
            if(!tr[cur].son[b]) {
                tr[cur].son[b] = tr.size();
                tr.emplace_back();
            }
            cur = tr[v].son[b];
            tr[cur].ps++;
        }
        tr[cur].end++;
	};
	
	
	//关键代码: find   这里不同于普通的 极值0-1trie:
	//字典树 -> find ：查询与 x 异或第 k 小的值
	auto find = [&](int x,int k) -> int {
		int cur = 0;
		int res = 0;  // res表示对应第k小的值；
		for(int i = 29;i >= 0;i--) {
			int need = (x >> i) & 1;
			int to = tr[cur].son[end];
			if(to && tr[to].ps >= k) {
				cur = to;
				res += (1 << i) * b;
			}
			else {
				if(to) k -= tr[cur].ps;
				cur = tr[cur].son[b ^ 1];
				res += (1 << i) * (b ^ 1);
			}
		}
		return res; 
	};
	
	for(auto& x : a) insert(x);
}
```


## 五、复杂度与优势总结

| **维度**      | **复杂度**                       | **说明**                            |
| ----------- | ----------------------------- | --------------------------------- |
| **时间复杂度**   | $O(\log V)$ 或 $O(30 \cdot N)$ | 每一位都需要做一次 30 层的循环下沉，单次查询极其高效。     |
| **空间复杂度**   | $O(N \log V)$                 | 动态开点 Trie，只有实际插入了数字才会新建节点，内存非常安全。 |
| **单次查询复杂度** | $O(\log V)$                   | 将暴力查询优化为二进制遍历贪心，时间复杂度对应位`log`级；   |
