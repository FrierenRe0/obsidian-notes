## 介绍：
0-1 字典树（0-1 Trie）是一种将整数按**二进制位**拆分存储的二叉树结构，专门用于高效解决**按位异或（XOR）极值查询**问题。


## 0-1字典树思路讲解：

**核心存储机制**

- **固定位数拆分**：将整数看作固定长度（如 32 位或 31 位）的二进制序列，从最高有效位（MSB，第 31 位）到最低有效位（LSB，第 0 位）逐位存入 Trie 树。
    
- **二叉树分支**：每个节点最多只有两个子节点 `son[0]` 和 `son[1]`，分别代表当前二进制位上的 `0` 和 `1`。

**两大核心操作**

- **插入操作（Insert）**
    
    对于每个数值 $V$：
    
    1. 从最高位开始取出第 $i$ 位二进制数值 $b \in \{0, 1\}$。
        
    2. 检查当前节点的 `son[b]` 分支是否存在，若不存在则新建节点。
        
    3. 沿 `son[b]` 分支向下移动，重复该过程直至处理完最低位。
        
- **贪心检索（Max XOR Query）**
    
    异或运算的性质是**同位为 0，异位为 1**（$1 \oplus 0 = 1$）。要让 $V \oplus X$ 的结果最大，关键在于**优先保证高位的异或结果为 1**。
    
    对于查询值 $V$：
    
    1. 从最高位开始取出第 $i$ 位二进制数值 $b$。
        
    2. **贪心选择**：优先检查是否存在相反的分支 `find = b ^ 1`：
        
        - **存在相反分支**：走 `son[find]`，并将当前位的贡献值 $2^i$ 计入总答案（此时该位异或结果为 1）。
            
        - **不存在相反分支**：迫不得已走相同分支 `son[b]`（此时该位异或结果为 0）。
            
    3. 沿所选分支继续向下一层遍历，直至到达最低位。


## 代码展示 ： 

**为了防止`MLE`，0-1字典树依旧是采用数组的动态开点方式，提高内存空间使用率**：

```c++
//这里的数据规模采用在: 2^(32)以内
struct Node {
	array<int,2> son{};
	//int ps = 0;
	int end = 0;
};

//这里我用lambda表达式写对于insert,ask两大基础接口：

void solve {
	
	vector<Node> tr;
	tr.emplace_back();
	
	//数字转化成"01"字符串处理 -> 标准32位int型长度
	//注意：
	//1.这里转化后的字符串是一个从高位到低位的字符串
	//2.同时标准32位长度达到二进制中“位对位”的准确定义
 	auto f = [&](int x) -> string { 
		return bitset<32>(x).to_string();
	};
	
	//insert:
	auto insert = [&](string s) -> void {
		int cur = 0;
		//++tr[cur].ps;
        for (auto &c : s)
        {
            int idx = c - '0';
            if (!tr[cur].son[idx])
            {
                int next = tr.size();
                tr.emplace_back();
                tr[cur].son[idx] = next;
            }
            cur = tr[cur].son[idx];
	        //++tr[cur].ps;
        }
        //++tr[cur].end;
	};
	//init:初始01字符串集 -> 01-trie
	insert(f(0));
	
	auto ask = [&](string& s) -> void {
		int now = 0;
        int cur = 0;
        for (int i = 0; i < 32; i++)
        {
            int bit = 31 - i;
            int x = s[i] - '0';
            int find = (x ? 0 : 1);
            
            //这里对于每个节点一共就2个孩子（0/1），不是1就是0
            //所以类似于线段树递归，一定可以下滑到底
            //在必选一个中不存在没找到
            //也就不存在 if(!tr[cur].son[idx]) return ;的这种情况了
            
            if(!tr[cur].son[find])
            {
                cur = tr[cur].son[x];
            }
            else
            {
                now += (1LL << bit);
                cur = tr[cur].son[find];
            }
        }
	}; 

}
```
