## 一、 什么是笛卡尔树？

**笛卡尔树**：输入是一个**一维序列**（或带有索引和数值的键值对数组）。数组的下标构成了中序遍历的 BST 顺序，而数组的元素值构成了堆的优先级。它的重点在于**把数组的局部极值关系转化为树的祖先-后代关系**。
**这里对比`treap`树**：
**Treap**：如果是一次性插入所有元素，也可以通过笛卡尔树的思想在 $O(N)$ 时间内自底向上构建；但在日常使用中，Treap 更多是通过连续的动态插入、分裂或合并来维护的，单次操作的时间复杂度为 $O(\log N)$。

笛卡尔树是一种特殊的二叉树，它结合了二叉搜索树（BST）**和**堆（Heap）的性质：

1. **中序遍历性质（BST 性质）**：如果把原数组的**下标**看作键值，树的中序遍历顺序恰好就是原数组的下标顺序（即左子树的下标都小于根节点，右子树的下标都大于根节点）。
    
2. **堆性质**：如果把原数组的**数值**看作权值，父节点的值满足堆的性质（以**小根堆**为例，父节点的值小于或等于左右子节点的值）。

逻辑上： 
	
- 相同点 ：有点st表的韵味，都是静态的同时都是表示表示对应子区间的极值；
	
- 不同点 ：
	- 在逻辑结构上不同，笛卡尔树是把数组的局部极值关系转化为树的祖先-后代关系，且每个节点的管辖区间并不像`线段树/st表`那样分治出的子区间，而是表示以 `a[i]` 为最小值的最大连续子区间 `[L, R]`，而节点的`val`表示的是包含该(点/下标)区间的最左段极值;
	- 而st表对应的管辖维护的是一个分治区间的极值；

> **核心结论**：给定一个一维数组，其小根堆笛卡尔树是**唯一确定**的。





## 二、 核心性质与应用场景

### 1. 区间极值管辖范围（最核心性质）

在小根堆笛卡尔树中，**以节点 $i$ 为根的子树，其包含的所有原数组下标范围，恰好对应了以 `a[i]` 为最小值的最大连续子区间 `[L, R]`**。

- 这意味着：如果你想知道某个元素作为“最小值”能向左、向右扩展多远，直接利用笛卡尔树的子树范围或单调栈边界即可解决。


### 2. 常见应用

- **单调栈/单调队列的树形抽象**：许多涉及“子数组最小值/最大值之和”、“柱状图中最大矩形”、“最大宽度与高度乘积”的题目，底层本质上就是在操作笛卡尔树。
    
- **RMQ（区间最值查询）转化**：数组的区间最小值问题（RMQ）可以等价转化为笛卡尔树上的最近公共祖先（LCA）问题。

#### 补充 ：
### 这里对于笛卡尔树在`RMQ`背景下提出一个深层的“灵魂拷问”：

如果我们只是为了做 **纯粹的区间最值查询（RMQ）**：

- 直接对原数组建一个 **ST 表**：预处理 $O(n \log n)$，查询 **$O(1)$**。
    
- 用笛卡尔树转倍增 LCA：预处理 $O(n \log n)$，查询 **$O(\log n)$**。
    

你会发现：**纯查 RMQ 的话，笛卡尔树 + 倍增 LCA 的查询速度（$O(\log n)$）反而比直接用 ST 表（$O(1)$）还要慢！**

### 那么，什么时候才真正需要“笛卡尔树”呢？

笛卡尔树的真正威力**不在于单纯替代 ST 表查静态 RMQ**，而在于**当题目不仅要区间最值，还要结合树形结构进行复杂统计时**。例如：

1. **结合子树性质的计数问题**（如“所有子数组最小值之和”、“柱状图中最大矩形”等，利用子树对应连续区间的性质）。
    
2. **树上 DP 或合并**（比如两棵笛卡尔树的合并、树上路径权值统计）。
    
3. **需要利用树的拓扑结构**（例如某些题目要求利用树的形态做启发式合并、点分治等）。






## 三、 $O(n)$ 高效构建算法（单调栈法）

我们通常利用**单调栈**来在 $O(n)$ 时间内构建笛卡尔树。单调栈在构建过程中维护的是笛卡尔树的“右链（Right Spine）”（即从根节点一直向右子树走所经过的节点轨迹）。

**构建步骤（以小根堆为例）：**

1. 遍历数组，用栈维护当前右链上的节点（栈中元素自底向上权值单调递增，对应下标单调递增）。
    
2. 当遇到新元素 `a[i]` 时，不断弹出栈顶比 `a[i]` 大的元素。最后一个被弹出的元素，将成为 `a[i]` 的**左儿子**。
    
3. 此时如果栈不为空，原栈顶元素的**右儿子**就要指向 `a[i]`。
    
4. 将 `a[i]` 压入栈中。





## 四、 竞赛算法模板（C++ / 1-Indexed）

下面是算法竞赛中最常用的标准小根堆笛卡尔树模板：
```c++
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define endl '\n'
#define ctz __builtin_ctzll         // 二进制表示中末尾连续0的个数
#define clz __builtin_clzll         // 二进驻表示中先导0的个数
#define count1 __builtin_popcountll // 二进制表示中1的个数
const int mod = 1e9 + 7;
const int MOD = 998244353;
const int N = 2e5 + 7;

void solve() { 
    int n;
    cin >> n;
    vector<int> a(n + 1);
    for(int i = 1;i <= n;i++) cin >> a[i];
    
    //笛卡尔树 - 用left,right来建立笛卡尔树（图）的信息；
    //left , right 对应是每个节点的左右孩子的下标；
    vector<int> left(n + 1),right(n + 1);
    auto build = [&]() -> void {
        stack<pair<int,int>> st;
        for(int i = 1;i <= n;i++) {
            int k = 0;
            while(!st.empty() && st.top().second > a[i]) {
                k = st.top().first;
                st.pop();
            }
            if(!st.empty()) {
                right[st.top().first] = i;
            }
            if(k) {
                left[i] = k;
            }
            st.push(make_pair(i,a[i]));
        }
    };
    build();
    
    return;
}
signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(0);
    int T = 1;
    //cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```
