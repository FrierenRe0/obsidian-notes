## 理解：

**单调队列 -> 单调双端队列**

大多数类似于这两者结合：
- 滑动窗口（算法思想）这里只是思想上有异曲同工，但是某些时候题目情况不同，还要具体分析
- 单调栈 （数据结构deque维护优化） 


## 注意在遇到不同情景问题：

要弄清楚 deque 入队，出队 ，更新答案的顺序选择：

**有两种情况：**
- 如果更新答案时，用到的数据包含当前元素，那么就需要先入队，再更新答案；[239. 滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum/)
- 如果用到的数据不包含当前元素，那么就需要先更新答案，再入队。[1499. 满足不等式的最大值](https://leetcode.cn/problems/max-value-of-equation/)
至于出队，一般写在前面，每遍历到一个新的元素，就看看队首元素是否失效（不满足要求），失效则弹出队首。


## 模板：
```c++
// 计算 nums 的每个长为 k 的窗口的最大值
// 时间复杂度 O(n)，其中 n 是 nums 的长度
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    int n = nums.size();
    vector<int> ans;
    ans.reserve(n - k + 1);
    deque<int> dq;
    for(int i = 0;i < n;i++) {
	    //因为这里再更新答案时需要用到当前元素，所以时先入队，（+不合法左移左端点）在更新答案
    
	    //1.右出队
        while(!dq.empty() && nums[dq.back()] <= nums[i]) {
            dq.pop_back();// 维护 q 的单调性
        }
        dq.push_back(i);//入队，注意这里保存的是下标，这样下面可以判断队首是否离开窗口
        
        //2.定长窗口，左端点右移
        while(l <= r && r - l + 1 > k) {
            if(dq.front() == l) dq.pop_front();//deque中储存下标的好处就是在这，可以准确deque中存放元素的位置来确定是否左出队
            l++;
        }
        
        //3.更新答案
        if(i >= k - 1) ans.push_back(nums[dq.front()]);
    }
    return ans;
}
```
