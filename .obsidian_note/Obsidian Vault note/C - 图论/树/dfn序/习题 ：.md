## 题目1 ： 时间戳 + dfn后缀和

### 链接 ：[3331. 修改后子树的大小 - 力扣（LeetCode）](https://leetcode.cn/problems/find-subtree-sizes-after-changes/description/?envType=daily-question&envId=2026-11-21)
### 核心思路

1. **只向祖先移动带来的单调性**：对任意节点 $u$，只有原本在 $u$ 子树内的节点可能留下来或移出去；原树中位于 $u$ 子树之外的节点永远不可能移入 $u$ 的子树。因此，每个节点的最终子树大小完全由其原树后代的迁移决定。
    
2. **DFS 序拍平子树**：记录每个节点的入栈时间 $\text{tin}[u]$ 和出栈时间 $\text{tout}[u]$，节点 $u$ 在原树中的整棵子树对应连续区间 $[\text{tin}[u], \text{tout}[u]]$。
    
3. **倒序结算 + 动态 dfn 后缀和**：按时间戳从 $n - 1$ 到 $0$ 倒序处理节点（天然自底向上）。每算出节点 $u$ 的最终子树大小后，将迁出/迁入带来的大小变动记在它的原父节点和新父节点处；由于修改位置严格在当前时间戳左侧，右侧已经算好的后缀和不会被破坏，直接用后缀和作差即可 $O(1)$ 得到每个节点的子树总变动量。


### 算法步骤拆解

#### 1. 计算时间戳与初始子树大小（`dfs`）

从根节点 `0` 开始做一次标准 DFS，记录：

- `tin[u]`：节点 $u$ 的 DFS 序（时间戳），范围 $[0, n - 1]$。
    
- `node[t]`：时间戳 $t$ 对应的原树节点编号，满足 `node[tin[u]] == u`。
    
- `tout[u]`：节点 $u$ 子树中最大的 DFS 序，子树区间为 $[\text{tin}[u], \text{tout}[u]]$。
    
- `sz[u]`：节点 $u$ 在**原树**中的初始子树大小。


#### 2. 确定每个节点的新父节点（`dfs1`）

维护 26 个字符栈 `cnt[26]`，在**后序遍历**（回溯阶段）中批量认领后代：

- 进入节点 $u$（字符下标为 `idx`）时，先记下当前栈大小 `start = cnt[idx].size()`，再递归遍历所有子节点。
    
- 当 $u$ 的所有子树递归完毕后，`cnt[idx]` 中下标在 `[start, cnt[idx].size() - 1]` 之间的节点，恰好是 **$u$ 的子树中所有与 $u$ 同字符、且尚未被更深祖先认领的后代**。
    
- 对这些后代而言，$u$ 就是离它们最近的同字符祖先，直接将它们的 `newParent` 设为 $u$，用 `cnt[idx].resize(start)` 出栈，最后将 $u$ 自身压栈，等待更浅的祖先认领。
    
- 每个节点仅入栈一次、出栈至多一次，总时间复杂度为 $O(n)$。


#### 3. 倒序遍历 + 变动量统计 + dfn 后缀和

用数组 `diff`（按 DFS 序索引）记录每个节点因孩子迁出或迁入产生的**直接大小变动量**。

设节点 $u$ 最终的子树大小为 $\text{sz}[u]$。若 $u$ 从原父节点 $p = \text{parent}[u]$ 改挂到新父节点 $y = \text{newParent}[u]$，则只需做两笔记录：

- 原父节点 $p$ 失去了一棵大小为 $\text{sz}[u]$ 的子树：$\text{diff}[\text{tin}[p]] \mathrel{-}= \text{sz}[u]$
    
- 新父节点 $y$ 获得了一棵大小为 $\text{sz}[u]$ 的子树：$\text{diff}[\text{tin}[y]] \mathrel{+}= \text{sz}[u]$

**为什么可以边倒序遍历边维护后缀和 `suf`？**

这依赖 DFS 序的两个严格大小关系：

1. **后代先结算**：节点 $u$ 的所有原树后代时间戳都大于 $\text{tin}[u]$。当循环变量 $t$ 从 $n - 1$ 倒序走到 $\text{tin}[u]$ 时，$u$ 的所有后代都已经算出最终大小，并把对应的增减写入了 `diff`。
    
2. **写入不影响已算后缀和**：节点 $u$ 结算完 $\text{sz}[u]$ 后，只会修改 `diff[tin[p]]` 和 `diff[tin[y]]`。由于祖先的入栈时间严格小于后代，必有：
    
    $$\text{tin}[y] \lt \text{tin}[p] \lt \text{tin}[u] = t$$
    
    所有新写入都落在 $t$ 的**严格左侧**，`diff[t]` 及右侧 `[t + 1, n - 1]` 的值早已固定，永远不会被改写。
    

因此可以直接递推维护后缀和：

$$\text{suf}[t] = \text{diff}[t] + \text{suf}[t + 1]$$

节点 $u$ 的子树总变动量即为区间和 $\text{suf}[t] - \text{suf}[\text{tout}[u] + 1]$，加到初始子树大小 $\text{sz}[u]$ 上即得最终结果。

### 代码+注释 ：
```c++
class Solution {
public:
    vector<int> findSubtreeSizes(vector<int>& parent, string s) {
        int n = s.size();
        vector<vector<int>> graph(n);
        for (int i = 1; i < n; i++) {
            graph[parent[i]].push_back(i);
        }

        // 1. 求 DFS 序（子树区间 [tin[u], tout[u]]）与原树初始子树大小
        vector<int> sz(n, 1);
        vector<int> node(n), tin(n), tout(n);
        int nod = 0;
        auto dfs = [&](this auto&& dfs, int u) -> void {
            tin[u] = nod;
            node[nod++] = u;
            for (int next : graph[u]) {
                dfs(next);
                sz[u] += sz[next];
            }
            tout[u] = nod - 1;
        };
        dfs(0);

        // 2. 后序栈批量匹配每个节点最近的同字符祖先
        vector<int> newParent = parent;
        vector<vector<int>> cnt(26);
        auto dfs1 = [&](this auto&& dfs1, int u) -> void {
            int idx = s[u] - 'a';
            int start = cnt[idx].size();
            for (int next : graph[u]) {
                dfs1(next);
            }
            // [start, end) 为 u 子树内尚未匹配到更近祖先的同字符后代
            for (int k = start; k < (int)cnt[idx].size(); k++) {
                newParent[cnt[idx][k]] = u;
            }
            cnt[idx].resize(start);
            cnt[idx].push_back(u);
        };
        dfs1(0);


        // 3. 按时间戳倒序结算：动态维护 dfn 后缀和，统计子树净变动量
        vector<int> diff(n, 0);
        vector<int> suf(n + 1, 0);
        for (int t = n - 1; t >= 0; t--) {
            int u = node[t];
            // 此时 diff[t..n-1] 已全部定型，递推后缀和并累加 u 子树内的总变动量
            suf[t] = diff[t] + suf[t + 1];
            sz[u] += suf[t] - suf[tout[u] + 1];

            // 若 u 发生改挂，将失去/获得的子树大小记到左侧的原父节点与新父节点上
            if (u != 0 && newParent[u] != parent[u]) {
                diff[tin[parent[u]]] -= sz[u];
                diff[tin[newParent[u]]] += sz[u];
            }
        }
        
        return sz;
    }
};
```
