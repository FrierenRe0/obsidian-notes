它的核心思想是：**为图中的每个节点存储一个列表，用来记录从该节点出发能够直接到达的所有节点及边权**。

邻接表特别适合存储**稀疏图**（边数 $M$ 远小于 $N^2$ 的图），其空间复杂度为 $\mathcal{O}(N + M)$。

### 两种主要的 C++ 实现方式

在 C++ 中，邻接表通常有以下两种主流实现方式：

#### 1. 基于 `std::vector` 的动态数组实现（推荐用于日常编程、面试和绝大多数竞赛题）

代码极简，易于理解和调试，内存按需分配。

## 1.稀疏表的建立

```c++
1.对于邻接表的板子：(含边权)

vector<vector<pair<int, int>>> graph(n + 1);  // 节点编号1~n，所以大小为n+1

for (int i = 0; i < m; ++i) {

    int u, v, w;// u,v 是两个节点，w是两个节点的边权

    cin >> u >> v >> w;

    //下面写法是建一个无向边

    //如果是有向边根据方向写一个就行

    graph[u].emplace_back(v, w);  // 无向图：u→v，权重w

    graph[v].emplace_back(u, w);  // 无向图：v→u，权重w

}

```


#### 2. 基于静态数组模拟链表的实现（即“链式前向星”）

这里可以看到`链式前向星`静态数组建图；

也就是我们刚才搭建完成的模板。通过 `head`、`nxt`、`to`、`weight` 静态数组来模拟链表的头插法。

- **优点**：无需动态分配内存，CPU 缓存命中率更高，常数极小，适用于严苛限时的卡常题目。
    
- **缺点**：代码相对繁琐，指针/下标移动逻辑需要格外小心。
