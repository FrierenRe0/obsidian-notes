邻接矩阵（Adjacency Matrix）是图论中最直观、实现最简单的一种存图方式。

它的核心思想是：**使用一个二维数组 `matrix[u][v]` 来表示节点 $u$ 到节点 $v$ 之间是否存在边以及边的权值**。

### 一、 C++ 标准模板实现

在处理带权图时，通常用一个极大值（如 `INF = 0x3f3f3f3f` 或 `1e18`）表示节点之间没有边相连，用 `0` 表示节点到自身的距离。

#### 1. 静态数组实现（ACM / 算法竞赛常用）


```c++
#include <bits/stdc++.h>
using namespace std;
#define int long long

const int N = 2500 + 5;           // 邻接矩阵空间开销为 O(N^2)，N 一般不超过 2500~5000
const int INF = 0x3f3f3f3f3f3f3f3fLL; // 极大值，表示无边

int g[N][N]; // g[u][v] 表示从 u 到 v 的边权

// 图初始化函数
void init_graph(int n) {
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (i == j) g[i][j] = 0;   // 自己到自己的距离为 0
            else g[i][j] = INF;        // 初始状态假设节点间无边
        }
    }
}

// 加边函数
void add_edge(int u, int v, int w, bool vis) { 
    // 若存在重边（Parallel Edges），这里我们保留最小权值的
    // 注意 : 但是如果需要保存重边，邻接矩阵是解决不了的
    g[u][v] = min(g[u][v], w); 
    if (vis) g[v][u] = min(g[v][u], w); // 这里表示如果是无向图双向，则双向加边
}

// 遍历节点 u 的所有邻居
void traverse(int u, int n) {
    cout << "节点 " << u << " 的邻接节点：";
    for (int v = 1; v <= n; v++) {
        if (u != v && g[u][v] != INF) {
            cout << "-> " << v << "(权值:" << g[u][v] << ") ";
        }
    }
    cout << endl;
}
```

### 二、 邻接矩阵的操作效率分析

|**操作**|**复杂度**|**说明**|
|---|---|---|
|**空间复杂度**|$\mathcal{O}(N^2)$|需要开辟 $N \times N$ 大小的二维数组|
|**检查是否存在边 $(u, v)$**|$\mathcal{O}(1)$|**极快**，只需检查 `g[u][v] != INF`|
|**修改/查询边权 $(u, v)$**|$\mathcal{O}(1)$|直接读写 `g[u][v]`|
|**遍历节点 $u$ 的所有出边**|$\mathcal{O}(N)$|无论节点 $u$ 有多少条边，都必须扫描整整一行 $N$ 个元素|

### 三、 适用场景与局限性

#### 1. 适用场景（何时使用邻接矩阵？）

- **稠密图（Dense Graph）**：边数接近最大可能值（即 $M \approx N^2$）。
    
- **节点数较小**：节点数量 $N \le 2500$（如果 $N = 10^5$，开 $10^5 \times 10^5$ 的 `long long` 数组需要约 $80 \text{ GB}$ 内存，直接导致内存超限 MLE）。
    
- **算法需求**：
    
    - **Floyd-Warshall 全源最短路算法**：天然基于邻接矩阵进行动态规划，代码仅需 3 层 `for` 循环。
        
    - 需要频次极高地判断任意两点之间是否存在边。
	
#### 2. 局限性（何时避免使用？）

- **稀疏图（Sparse Graph）**：例如 $N = 10^5, M = 2 \times 10^5$，邻接矩阵会浪费 99.99% 的空间去存 `INF`。
    
- **存在重边且需要全部保留**：邻接矩阵同一位置只能存一条边，如果问题要求保留重边的多条独立状态，邻接矩阵无法处理（只能保留极值）。
