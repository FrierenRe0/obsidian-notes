**容斥原理是我们高中就有接触过的数学知识，该经典图片就明确表示了其原理

![截图](../../../截图文件/Pasted%20image%2020260723152444.png)
$$\vert{}A \cup B \cup C\vert{} = \vert{}A\vert{} + \vert{}B\vert{} + \vert{}C\vert{} - \vert{}A \cap B\vert{} - \vert{}A \cap C\vert{} - \vert{}B \cap C\vert{} + \vert{}A \cap B \cap C\vert{}$$

**推广为：
$$\left\vert{} \bigcup_{i=1}^n A_i \right\vert{} = \sum_{k=1}^n (-1)^{k-1} \sum_{1 \le i_1 < i_2 < \dots < i_k \le n} \vert{}A_{i_1} \cap A_{i_2} \cap \dots \cap A_{i_k}\vert{}$$

**代码如下 + 解析（更易理解）：

```c++
int num;//这里表示就是有num个集合

//这里f函数功能：计算所有集合的并集
int f() {
	//每单个集合->"选与不选"映射到二进制i表达上 
	//bit[i] == 0 表示a中下标为i的集合不选；
	//否则，bit[i] == 1,表示a中下标为i的集合选；
	//由数学组合原理（选与不选）易得有i可以有(1 << num) - 1中选法；
	if(num <= 0) return 0;
	int ans = 0;
	for(int i = 1;i < (1 << num);i++) {
		int sum = 0; // sum 表示在这个状态一共所选择的数量
		int temp = 0; // 该状态对应的集合大小
		for(int j = 0;j < num;j++) {
			int vis = (i >> j) & 1;
			if(vis) {
				sum++;
				temp = ;//这里变为选上该集合后的交集大小
			}
			if(!temp) break;
		}
		if(sum & 1) ans += temp;
		else ans -= temp;
	}
	return ans;
}
void solve() {
	cin >> num; 
	int all = f();
}
```
