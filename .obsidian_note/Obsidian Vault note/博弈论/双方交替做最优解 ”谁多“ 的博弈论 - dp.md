## 博弈论的解法：

- **贪心**  -> 写法相对活跃 -> 但是八九不离十，都是一个”从下到上的思考过程“
- **dp**  /  **记忆化搜索** **（这里在竞赛中常常出现）** ->  解决状态的最值求解
- **分类讨论** -> 适用情况较少，在上面两种不好用，同时状态树的逻辑路线很少的情况下可以


## 本质：就是再求对于当前状态下找出最值的问题 ，而这就是个dp过程
## 为什么 ？

### 解释：确定性消除了“博弈的不确定性” 
->同时，这里我会对  dp / 记忆化搜索   思路做一些引入讲解 

当双方都**绝对理性**且**掌握完整信息**时，对手的行为不再是一个“随机变量”或“心理猜测”，而变成了一个**已知的确定函数**。

- 你不需要猜测对手会怎么走，因为你知道他一定会选择让你收益最小（对他最有利）的那一步。
    
- 既然对手的选择是可预测的函数 $f(s)$，博弈就退化成了“你对 $f(s)$ 求最大值”的单人优化问题。


### 1.思维逻辑抽象： 状态树（博弈树）的倒推拓扑序

博弈的状态可以抽象为一张**有向无环图(DAG)**  或  **博弈树**：

- **终局状态（叶子节点）：** 胜负状态是确定的（例如：赢 $= +1$，输 $= -1$；或 SG 值为 $0$）。
    
- **非终局状态：** 每一个状态的值，完全由它的后继状态决定。
    
- **极大极小定理（Minimax）：**
    $$V(\text{当前状态}) = \max_{\text{你的合法动作}} \left( \min_{\text{对手的合法动作}} V(\text{后续状态}) \right)$$
    
    因为递归的底层是确定的，所以自底向上求解的过程，本质上就是沿着博弈树做动态规划（DP）或带记忆化搜索（DFS）去求最值。


#### 所以，在博弈论中的选择路径是一个确定的情况；

- **记忆化搜索（递归)**
	- 节点定义：每一层都为当下的最(大/小)值状态
	- 根据当前（根）节点和对应的子节点的状态转移关系，记忆化搜索（递归 + 记忆减枝）完成对于当前状态下最值求解
	- 最后根据题目提问，（一般都是根节点状态），根据节点的值对应输出
	
- 递推： 
	- 说白了就是在递归的基础上减少了从上到下（从根到叶）的过程，或者说是删掉了”递“，直接从叶子节点开始dp完成”归“的过程
	- 叶子节点就是在”归“过程中需要的初始状态，从叶子层的上一个状态开始，根据状态转移关系，可以依靠他们对应的子节点完成对于当前状态下最值求解


**总结：** 只要没有随机因素（如掷骰子）和隐藏信息（如扑克牌手牌），**所谓的“博弈”，本质上就是图上的最短/最长路径或状态最值求解问题**。
