####     [1872. 石子游戏 VIII](https://leetcode.cn/problems/stone-game-viii/)
##### 解题思路与推导

1. **前缀和转化**
    
    - 注意到无论怎么操作，新放回最左侧的石子价值总是等于被拿走的所有石子的总和。
        
    - 因此，选择前 $x$ 堆石子获得的分数，正好对应原数组的前缀和 $pre[x-1]$（即前 $x$ 个元素的累加和）。
        
    - 移除前 $x$ 堆石子后，原数组剩下的石子加上合并的新石子，本质上就相当于**后续玩家只能从 $x$ 之后的索引继续选择前缀和**。
        
2. **状态定义**
    
    - 定义 `dp[i]` 表示：**当当前玩家只能在索引从 $i$ 到 $n-1$ 中选择前缀和作为操作点时，当前玩家与对手的最大分数差**。
        
3. **状态转移方程**
    
    - 如果当前玩家选择在索引 $i$ 处切分（即拿走前 $i+1$ 堆石子）：
        
        - 本轮获得分数为 $pre[i]$。
            
        - 下一位玩家面对的剩余决策范围是索引从 $i+1$ 到 $n-1$，其能获得的最大相对优势为 `dp[i + 1]`。
            
        - 此时当前玩家的分数差为：$pre[i] - dp[i + 1]$。
            
    - 如果当前玩家不在索引 $i$ 处切分，而是放弃该位置，将决策转移到索引大于 $i$ 的位置，则最大收益为：`dp[i + 1]`。
        
    - 因此状态转移方程为：
        $$\text{dp}[i] = \max(\text{dp}[i + 1], pre[i] - \text{dp}[i + 1])$$
		通过这样定义，对于每一层状态我们只要看他相邻的单一子问题就行，从而对于所有选取到 $\ge$ i + 1 的情况就可以统一用$dfs[i + 1]$一个状态表示，大幅提高运行效率，可以做到$o(n)$时间复杂度
	
1. **dfs边界条件 / dp初始点**
    
    - 由于规则要求每次至少拿 $2$ 堆石子（即 $x \ge 2$），最晚必须在最后一堆结束。
        
    - 当只剩最后一个决策点 $n-1$ 时，玩家别无选择，必须拿走所有石子，因此：
        $$\text{dp}[n - 1] = pre[n - 1]$$
        
    - 游戏从至少选择前 2 堆石子开始（对应索引 1），所以答案即为 `dp[1]`。

###### 代码剖析与空间优化

```c++
class Solution {
public:
    int stoneGameVIII(vector<int>& stones) {
        int n = stones.size();
        
        // 1. 计算前缀和数组
        vector<int> pre(n);
        int sum = 0;
        for (int i = 0; i < n; i++) {
            sum += stones[i];
            pre[i] = sum;
        }
        
        // 2. 倒序动态规划
        vector<int> dp(n);
        dp[n - 1] = pre[n - 1]; // 边界条件：必须选到最后
        
        for (int i = n - 2; i >= 1; i--) {
            dp[i] = max(dp[i + 1], pre[i] - dp[i + 1]);
        }
        
        // 3. dp[1] 代表至少选择前 2 堆（索引 1）时的全局最优解
        return dp[1];
    }
};
```
