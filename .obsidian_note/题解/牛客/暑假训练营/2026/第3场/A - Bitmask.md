## 一 . 思路：

这里如果我们在对应操作完去暴力的找连续 $bit == 1$区间的数量的话，时间复杂度为 $o(n * m)$ 级别(这里的m表示每个$a[i]$对应的二进制长度)
### 那我们需要如何不用 $o(n * m)$级别的时间复杂度来完成对于n个元素的操作呢？？
#### 1. 核心转化：

题目要求计算 $x$ 的二进制表示中连续的 1 的段数 $f(x)$。

在二进制中，一段连续的 1 的右边界必然是一个从低位到高位 **由 1 变为 0** 的跳变（即第 $j$ 位是 1，第 $j+1$ 位是 0）。如果我们假设最高位再往左是无穷多个 0，那么：
$$f(x) = \sum_{j=0}^{29} [ (x \text{ 的第 } j \text{ 位} == 1) \land (x \text{ 的第 } j+1 \text{ 位} == 0) ]$$
因此，所有数字的 $f(a_i)$ 之和，可以转化为对每一对相邻位 $(j, j+1)$ 满足 $1 \to 0$ 跳变的总数计数。


#### 2. 位运算的关键理解 ：位与位之间的解耦（独立计算，互不干扰）

- 位运算有一个天然的数学特性：**第 $j$ 位上发生什么操作，完全由操作数 $x$ 的第 $j$ 位决定，绝不会向第 $j+1$ 位进位或借位，则这里可以对原数组每个元素在相应的位置上进行二进制初始映射统计。**

- **也就是说，每个分隔看的位置在位运算操作中都是相对独立的，则每次操作后所得的统计结果就是将每个分隔的位置进行独立更新，所得到在该位置上操作后的统计情况

- **又因为所有数字的 $f(a_i)$ 之和，可以转化为对每一对相邻位 $(j, j+1)$ 满足 $1 \to 0$ 跳变的总数计数，这里个每个分隔位置采用两两相邻pair的方式，便可完成对于所有元素操作完的$[0][1]$情况的准确统计
#### 3. 对于操作之后，输出 $\sum_{i=1}^n f(a_i)$ 完全等价于 $\sum_{i=1}^{30} cnt[i][1][0]$


## 二 . 对应代码如下：
```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const int N = 3e5 + 5;

int cnt[30][2][2];
int n, m;
int a[N];
int get(int x, int p) { return (x >> p) & 1; }

void solve() {
    cin >> n;
    for (int i = 0; i < n; i++) {
	    cin >> a[i];
	    //对应的分隔情况采用两个两个pair
	    //  6    5    4    3    2    1    0   :bit[i】位：对应a[i]的二进制形式
	    // ---  ---  ---  ---  ---  ---  ---  : 对应0或1
		//  |    |    |    |    |    |    |
	    // ---------------------------------                    
		//   [5]  [4]  [3]  [2]  [1]  [0]     :分隔划定的下标i
		//   5+6  4+5  3+4  2+3  1+2  0+1     :每个分隔的下标对应在二进制中的相邻bit位
	    
        for (int j = 0; j < 30; j++) {
            cnt[j][get(a[i], j)][get(a[i], j + 1)]++;
        }
    }

    cin >> m;
    while (m--) {
        int o, x;
        cin >> o >> x;

        auto f = [&](int x, int y) -> int {
            if (o == 1)
                return x & y;
            else if (o == 2)
                return x | y;
            else
                return x ^ y;
        };
        
        for (int i = 0; i < 30; i++) {
            int nxt[2][2] = {0};
            int q = get(x, i), p = get(x, i + 1);

            for (int j = 0; j < 2; j++) {
                for (int k = 0; k < 2; k++) {
                    nxt[f(j, q)][f(k, p)] += cnt[i][j][k];
                }
            }

            for (int j = 0; j < 2; j++) {
                for (int k = 0; k < 2; k++) {
                    cnt[i][j][k] = nxt[j][k];
                }
            }
        }

        int ans = 0;
        for (int i = 0; i < 30; i++) ans += cnt[i][1][0];
        cout << ans << "\n";
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t = 1;
    // 	std::cin>>t;
    while (t--)
        solve();
    return 0;
}
```
