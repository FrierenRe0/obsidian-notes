## 题目大意：

![](../../../../../截图文件/Pasted%20image%2020260730180954.png)
给定一个字符串 $S$ 和一个整数 $k$。我们需要在 $S$ 的所有**循环移位**（共 $\vert{}S\vert{}$ 个）中，统计有多少个循环移位包含了特定的子串 $T_k$。

其中，子串 $T_k$ 的定义是字符串 `"Rounddo"` 后面紧跟 $k$ 个字符 `'g'`。


## 核心思路分析 (Approach)

解决这道题的难点有两个：

1. 如何优雅地处理“循环移位”？
    
2. 如果一个循环移位中多次出现 $T_k$，如何避免重复计数？


你的代码通过以下几个步骤完美解决了这两个问题：

### 1. 破环成链（字符串倍增）

处理字符串循环移位最常用、最简单的技巧就是将字符串复制一份拼接在原字符串后面，即令 $S' = S + S$。

对于长度为 $n$ 的原字符串 $S$，它的每一个循环移位，都等价于新字符串 $S'$ 中从索引 $i$ $(0 \le i < n)$ 开始、长度为 $n$ 的一个子串。

这样，我们就把一个“环形”问题转化为了普通的“线性”字符串匹配问题。

### 2. 构建目标子串 $T_k$ 并特判

根据题意，$T_k$ 的固定前缀是 `"Rounddo"`（长度为7），后面跟着 $k$ 个 `'g'`。所以目标子串的总长度为 $len = 7 + k$。

**特判：** 如果 $len > n$（目标子串比原字符串还要长），那么无论怎么循环移位都不可能包含它，直接输出 $0$ 即可。

### 3. 确定有效循环移位的区间（核心推导）

我们在倍增后的字符串 $S + S$ 中寻找目标子串 $T_k$。假设我们找到了一个匹配，它在 $S + S$ 中的起始下标为 $idx$。

那么，**哪些循环移位（即哪些起始下标 $i$）能够完整地包含这个匹配到的 $T_k$ 呢？**

设循环移位的起始下标为 $i$ $(0 \le i < n)$，该循环移位的区间是 $[i, i + n - 1]$。

匹配到的 $T_k$ 的区间是 $[idx, idx + len - 1]$。

要想让循环移位包含这个 $T_k$，必须同时满足两个条件：

1. 循环移位的左边界 $\le$ $T_k$ 的左边界：$i \le idx$
    
2. 循环移位的右边界 $\ge$ $T_k$ 的右边界：$i + n - 1 \ge idx + len - 1$ $\implies$ $i \ge idx + len - n$


综合上述两个条件，起始下标 $i$ 必须满足：

$$idx + len - n \le i \le idx$$

因为 $i$ 本身必须是合法的循环移位起点（即 $0 \le i < n$），所以我们对区间取交集，得到合法的 $i$ 的区间 $[L, R]$：

- $L = \max(0LL, idx + len - n)$
    
- $R = \min(n - 1, idx)$


如果 $L \le R$，说明这个匹配到的 $T_k$ 对区间 $[L, R]$ 内的所有循环移位都做出了贡献。


### 4. 差分数组统计覆盖 (避免重复计算)

一个循环移位里面可能会出现**多个** $T_k$，但题目问的是“有多少个循环移位包含”，所以即使包含多个，也只能算 1 次。

这是一个典型的**区间覆盖问题**。对于每一次匹配找到的区间 $[L, R]$，我们需要把这个区间内的元素“标记”一下。

为了在 $O(1)$ 时间内完成区间修改，代码使用了**差分数组** `diff`：

- `diff[L] += 1`
    
- `diff[R + 1] -= 1`
    

最后，只需要遍历 $0$ 到 $n-1$，求差分数组的**前缀和**。如果某个位置的前缀和大于 $0$，说明这个起始位置对应的循环移位至少包含了一个 $T_k$，答案（`ans`）就加一。

## 复杂度分析 

- **时间复杂度：**
    
    - 字符串拼接和构建 $T_k$：$O(N + K)$
        
    - 在 $S+S$ 中查找 $T_k$：使用的是 `std::string::find`。在最坏情况下时间复杂度是 $O(N \times \text{len})$，但在实际应用中以及绝大多数非极端构造的数据下，其效率非常接近 $O(N)$。由于题目保证所有测试用例中 $\vert{}S\vert{}$ 的总和不超过 $10^5$，这个查找是非常快的。
        
    - 差分数组维护与前缀和：$O(N)$
        
    - **总体时间复杂度：** $O(N)$ (近似)，完全可以通过本题的时间限制。
    
- **空间复杂度：**
    
    - 需要存储倍增后的字符串 $S+S$：$O(N)$
        
    - 差分数组 `diff`：$O(N)$
        
    - **总体空间复杂度：** $O(N)$

## 代码如下：
```c++
#include <bits/stdc++.h>
using namespace std;
#define int long long

void solve() { 
    string s;
    cin >> s;
    int k;
    cin >> k;
    
    int n = s.size();
    int len = 7 + k;
    
    if (len > n) {
        cout << 0 << endl;
        return;
    }
    
    string cur = "Rounddo";
    for(int i = 0; i < k; i++) cur += 'g';
    
    s = s + s;
    
    vector<int> diff(n + 2, 0);
    
    size_t idx = s.find(cur);
    while (idx != string::npos) {
        int L = max(0LL, (int)idx + len - n);
        int R = min(n - 1, (int)idx);
        
        if (L <= R) {
            diff[L] += 1;
            diff[R + 1] -= 1;
        }
    
        idx = s.find(cur, idx + 1);
        
        if (idx > 2 * n - len) break;
    }
    
    int ans = 0;
    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += diff[i];
        if (sum > 0) {
            ans++;
        }
    }
    
    cout << ans << endl;
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T = 1;
    cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```
