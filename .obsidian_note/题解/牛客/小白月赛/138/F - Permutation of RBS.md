## 题目大意：

给出一个长度为 $2n$ 的、非空的、合法的括号序列 $s$，其有 $n$ 个匹配的括号对。

你需要给每一对匹配的括号对赋值，满足：

- 所有括号对的权值形成一个长为 $n$ 的排列；
    
- 如果括号对 $A$ 在括号对 $B$ 的内层，$A$ 的权值必须大于 $B$ 的权值。

请你计算满足条件的赋值方案一共有多少种。由于答案可能很大，你只需要输出答案对 $10^9+7$ 取模后的值。


## 题解 ：

### 一、 核心转化：括号序列与树形结构

1. **树的对应关系**： 合法的括号序列天然与**树（或森林）结构**一一对应。每一对匹配的括号 `()` 可以看作树上的一个**节点**。如果括号对 $A$ 在括号对 $B$ 的内部，那么 $A$ 就是 $B$ 的**子节点**。
    
2. **大小关系转化**： 题目要求：“如果括号对 $A$ 在 $B$ 的内层，$A$ 的权值必须大于 $B$ 的权值”。 转换成树的语言就是：**在整棵树中，任意子节点的权值必须大于其父节点的权值**（即父节点的值小于子节点的值）。





### 二、 组合数学公式推导

在一个有 $n$ 个节点的树中，用 $1$ 到 $n$ 的排列去给节点赋值，使得**每个节点的权值都大于其父节点**，这样的合法赋值方案数有一个经典的组合数学公式：
$$\text{Ans} = \frac{n!}{\prod_{u} \text{sz}(u)}$$

- 其中 $n!$ 是全排列的总数。
    
- $\text{sz}(u)$ 表示以节点 $u$ 为根的子树的大小（包含节点 $u$ 本身）。
    
- $\prod_{u} \text{sz}(u)$ 表示所有节点及其子树的大小的乘积。


这个公式的直观理解是：在堆序树（Heap-ordered tree）中，每个节点在其子树中必须是最小的（或满足特定拓扑序），通过概率或hook length公式可以推导出分母正好是所有子树大小的乘积。

#### 这里对该公式进行推导 ：
##### 第一步：核心约束——“根节点必须是子树最小值”

题目要求：**内层（子节点）的权值必须大于外层（父节点）的权值**。

映射到树上，这意味着：**对于树中的任意一个节点 $v$，它必须是它这棵子树里所有节点中最小的那一个数。**

- 为什么？因为它是这棵子树的根（最外层），而所有后代都在它的内部（内层），后代都必须比它大。

##### 第二步：概率视角下的神奇推导

假设我们从 $1$ 到 $n$ 中**随机生成一个全排列**（总共有 $n!$ 种可能）。

我们来思考一个问题：**这个随机排列刚好满足“所有节点都小于其子孙（即每个子树的根都是该子树最小值）”的概率是多少？**

1. **单个节点的概率**：
    
    对于树中的某一个节点 $v$，其子树的大小为 $\text{size}(v)$。这意味着这棵子树里总共有 $\text{size}(v)$ 个数字。在这堆数字里，最小的那一个数字必须刚好落在根节点 $v$ 上。因为排列是随机的，根节点拿到这堆数里最小值的概率是：
    $$\frac{1}{\text{size}(v)}$$
1. **独立性（关键性质）**：
    
    在组合数学中有一个强有力的定理：**对于一棵树而言，各个子树的根节点是其子树最小值的事件，是完全相互独立的！**
    
    （直观理解：每个子树分配到的数值集合互不干扰，谁当最小值互不影响。）
    
2. **总概率计算**：
    
    既然每个节点的条件都是独立的，那么一个随机排列能够同时满足整棵树所有节点条件的**总概率 $P$**，就是把所有节点满足条件的概率乘起来：
    
    $$P = \prod_{v} \frac{1}{\text{size}(v)} = \frac{1}{\prod_{v} \text{size}(v)}$$
##### 第三步：得出最终公式

我们知道：
$$\text{满足条件的合法排列数} = \text{总排列数 } (n!) \times \text{ 随机排列满足条件的概率 } (P)$$

将概率 $P$ 代入：
$$\text{ans} = n! \times \frac{1}{\prod_{v} \text{size}(v)} = \frac{n!}{\prod_{v} \text{size}(v)}$$





### 三、 代码实现与栈的妙用

你提供的代码核心在于使用了一个栈（Stack）来在线性时间内计算分母 $\prod \text{sz}(u)$：

1. **栈的作用**： 栈用来维护当前正在处理的子树中，各个直接子树的大小。
    
2. **状态转移逻辑**：
    
    - **遇到 `(`**：代表开启了一个新的子树，我们在栈中压入 `0`，用来累加未来子树的大小。
        
    - **遇到 `)`**：代表当前子树闭合。当前子树的大小为 `sz = 1 + st.top()`（$1$ 代表当前节点本身，`st.top()` 代表其所有子节点的大小总和）。
        
        - 将这个 `sz` 乘入总积变量 `p` 中（即累乘分母）。
            
        - 如果栈不为空（说明还有外层父节点），把当前子树的大小 `sz` 累加到父节点的子树总和中：`st.top() += sz`。
            
3. **最终计算**： 分母计算完毕后，最终答案即为：
    
    $$\text{ans} = n! \times p^{-1} \pmod{10^9+7}$$
    
    代码中通过 `ksm(p, mod - 2)` 利用费马小定理求出 $p$ 在模 $10^9+7$ 意义下的乘法逆元。
    

### 四、 复杂度分析

- **时间复杂度**：$O(n)$。代码只需遍历一次长度为 $2n$ 的括号字符串，栈的操作均为 $O(1)$，求逆元和阶乘预处理的时间复杂度也很低。
    
- **空间复杂度**：$O(n)$。主要消耗在栈的深度（最大为 $n$）以及阶乘数组 `fac` 上。


## 代码展示：

```c++
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define endl '\n'
#define ctz __builtin_ctzll         // 二进制表示中末尾连续0的个数
#define clz __builtin_clzll         // 二进驻表示中先导0的个数
#define count1 __builtin_popcountll // 二进制表示中1的个数
const int mod = 1e9 + 7;
const int MOD = 998244353;
const int N = 5e5 + 7;

int fac[N];

int ksm(int n, int m){
    int res = 1;
    n %= mod;
    while(m){
        if(m & 1){
            res = res * n % mod;
        }
        n = n * n % mod;
        m = m >> 1;
    }
    return res;
}

int init = [](){
    fac[0] = 1;
    for(int i = 1; i < N; i++){
        fac[i] = fac[i - 1] * i % mod;
    }
    return 0;
}();

void solve() { 
    int n;
    cin >> n;
    string s;
    cin >> s;
    
    int p = 1;    
    stack<int> st;  
    
    for(auto& x : s) {
        if(x == '(') {
            st.push(0); 
        }
        else {
            int sz = 1 + st.top();
            st.pop();
            
            p = (p * sz) % mod; 
            
            if(!st.empty()) {
                st.top() += sz;       
            }
        }
    }
    
    int ans = fac[n] * ksm(p, mod - 2) % mod;
    cout << ans << endl;
    return;
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(0);
    int T = 1;
    cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```
