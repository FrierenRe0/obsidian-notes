## 题目大意：

- 有 $n$ 种香肠，每种的数量在 $[0, 15]$ 之间。
    
- 有 $q$ 次单点修改操作。
    
- 每次操作可以选择相邻的两个香肠 $a_i$ 和 $a_{i+1}$，将它们同时异或同一个掩码 $3 \cdot k$（其中 $1 \le k \le 5$）。
    
- 全肉味（All-Meat）定义为：数量能被 $3$ 整除。在 $[0, 15]$ 范围内，全肉味的值为：$0, 3, 6, 9, 12, 15$。
    
- 求：在进行任意次合法操作后，**最多**能有多少种香肠变成全肉味。初始及每次修改后都要输出答案。



## 评价 ：（前置知识）位运算奇偶性质

### 1. 数学原理：奇偶性加法法则

在二进制的异或（XOR）运算中，两个数 `1` 的个数（popcount）的奇偶性满足一个非常优美的同余性质：

$$\text{parity}(A \oplus B) \equiv \text{parity}(A) + \text{parity}(B) \pmod 2$$

如果把“奇数”记作 `1`，“偶数”记作 `0`：

- **奇数 + 偶数 = 奇数**（$1 + 0 \equiv 1 \pmod 2$）
    
- **奇数 + 奇数 = 偶数**（$1 + 1 \equiv 0 \pmod 2$）
    
- **偶数 + 偶数 = 偶数**（$0 + 0 \equiv 0 \pmod 2$）
    

所以，当你用一个**偶数个 `1`** 的数去异或另一个数时，原数字 `1` 的个数的**奇偶性是绝对不会改变的** ；反之，一定发生改变：

- 原本是**奇数**个 `1`，异或一个偶数个 `1` 的数后，**依然是奇数个 `1`**。
    
- 原本是**偶数**个 `1`，异或一个偶数个 `1` 的数后，**依然是偶数个 `1`**。


### 2. 为什么会这样？（直观理解）

异或运算的本质是“相同为 0，不同为 1”。

当我们把 $A$ 和 $B$ 异或时：

- 如果 $A$ 和 $B$ 在某些二进制位上**同时为 1**，异或后这些位会变成 0。也就是说，同时为 1 的位总是**成对（以 2 为单位）消去**的。
    
- 既然是成对消去（减去 $2k$ 个 `1`），那么它对整体 `1` 的个数的**奇偶性**不会产生任何影响。
    

### 3. 这对这道题意味着什么？

这正是这道题最核心的突破口：

1. 题目中允许的所有操作掩码（$3, 6, 9, 12, 15$），它们的二进制 `1` 的个数**全部都是偶数**（例如 3 有两个 1，15 有四个 1）。
    
2. 这意味着，**无论 Reyhaneh 做多少次操作，数字中 `1` 的个数的奇偶性是永远锁死的、无法改变的**。
    
3. 题目中所有的“全肉味”数值（$0, 3, 6, 9, 12, 15$）其 `1` 的个数**全部都是偶数**。
    
4. **结论：** 初始时 `1` 的个数为**奇数**的那些 sausage flavor，无论你怎么施加合法的操作，它的奇偶性永远是奇数，**永远不可能变成全肉味**！
    

这就是为什么我们一开始可以直接把它们归为 `cnt[0]`（无法挽救的点），而只去关心那些初始时 `1` 的个数为偶数的点。



## 思路：

### 条件1 . 全肉味数值的特征：

- 在 $[0, 15]$ 范围内，所有的全肉味数值为：$0, 3, 6, 9, 12, 15$。
    
- 观察它们的二进制 `1` 的个数，会发现它们全部都是**偶数个 `1`**。
    
- **重要结论：** 一个二进制下 `1` 的个数为**奇数**的香肠，**无论怎么操作，都永远不可能变成全肉味**。
    
- 由此我们可以得到一个天然的上限：
$$\text{最大答案} \le \#\{i \mid \text{popcount}(a_i) \text{ 是偶数} \}$$


### 条件2 . 可以对任意两个不相邻的元素施加操作：

**证明：通过连续对相邻对 $(i, i+1), (i+1, i+2), \dots, (j-1, j)$ 执行同一种掩码，中间的所有元素会因为异或了两次而保持不变，只有两端的 $a_i$ 和 $a_j$ 各自被异或了一次。这意味着我们可以对**任意两个指定元素**执行掩码操作。**



### 分类讨论：

1. **Case 1：数组中存在 `1` 的个数为奇数的元素**
    
    - 我们可以把这个奇数个 `1` 的元素当作“万能缓冲区”。
        
    - 利用它，可以把所有 `1` 的个数为偶数的元素全部变成 `0`（即变成全肉味）。
        
    - 此时，所有偶数个 `1` 的元素全部达成全肉味，而奇数个 `1` 的元素无法贡献答案。答案就是**所有偶数个 `1` 的元素总数**。
	
	
2. **Case 2：数组中所有元素的 `1` 的个数全都是偶数**
    
    - 我们可以选择 $a_1$ 作为基准，把后面所有元素 $a_2, a_3, \dots, a_n$ 全部清零，数组形态变为 $[x, 0, 0, \dots, 0]$。
        
    - 此时的总异或和 $x = a_1 \oplus a_2 \oplus \dots \oplus a_n$ 也必然是偶数个 `1`。
        
    - 如果 $x$ 是 $5$ 或 $10$（它们不是全肉味），我们可以对前两个元素执行一次异或 $3$：
        
        - $(5, 0) \longrightarrow (6, 3)$ （$6$ 和 $3$ 都是全肉味）
            
        - $(10, 0) \longrightarrow (9, 3)$ （$9$ 和 $3$ 都是全肉味）
            
    - **结论：** 即使在这种情况下，**全部 $n$ 个元素也都可以变成全肉味**，答案是 $n$。

**总结 ： 只需要统计更新popcount - (1) 为偶数的数量即可**；


## 代码展示：

```c++
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define endl '\n'
#define ctz __builtin_ctzll         // 二进制表示中末尾连续0的个数
#define clz __builtin_clzll         // 二进驻表示中先导0的个数
#define count1 __builtin_popcountll // 二进制表示中1的个数
const int mod = 1e9 + 7;
const int MOD = 998244353;
const int N = 2e5 + 7;

void solve() { 
    int n,q;
    cin >> n >> q;
    vector<int> a(n + 1);
    for(int i = 1;i <= n;i++) cin >> a[i];

    vector<int> cnt(2,0);//0 -> count 偶数, 1 -> count 奇数;
    
    auto sum = [&](int x) -> int {
        int s = 0;
        for(int i = 0;x >> i;i++) {
            int v = (x >> i) & 1;
            if(v) s++;
        }
        return s;
    };
    for(int i = 1;i <= n;i++) {
        auto x = a[i];
        int vis = sum(x);
        if(vis & 1) cnt[1]++;
        else cnt[0]++;
    }

    auto write = [&]() -> void {
        cout << cnt[0] << " ";
    };
    write();

    while(q--) {
        int idx,c;
        cin >> idx >> c;
        int x = a[idx];
        if(sum(x) & 1) cnt[1]--;
        else cnt[0]--;

        if(sum(c) & 1) cnt[1]++;
        else cnt[0]++;

        write();
        // 
        a[idx] = c;
    }
    cout << endl;
    return;
}
signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(0);
    int T = 1;
    cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```
