这个问题在算法和数学中非常经典 ，但这里我想通过数学的角度来解释**中位数贪心** 的基本逻辑，它本质上是求解$L_1$ 范数最小化问题（即距离之和最小化）。

要证明“选择中位数可以使通过 $+1$、$-1$ 让所有数字相等的总操作数最小”，我们可以从**直观的区间夹逼（成对抵消）**和**严格的导数极值法**两个角度来证明。

### 一、 问题建模

假设我们有一个包含 $n$ 个数字的数组，将其从小到大排序后为：

$$x_1 \le x_2 \le x_3 \le \dots \le x_n$$

我们的目标是找到一个目标值 $x$，使得所有数字变为 $x$ 所需的总操作数（即总代价） $f(x)$ 最小：

$$f(x) = \sum_{i=1}^n \vert{}x_i - x\vert{}$$

### 二、 证明方法一：直观与成对抵消（几何意义）

我们可以把数组中的每个数字看作数轴上的一个点。我们要找一个点 $x$，使得它到所有点的**距离之和最小**。

1. **极端情况（只有两个点）：** 如果有两个点 $x_1$ 和 $x_n$，我们要找一个点 $x$ 到它们的距离之和 $\vert{}x_1 - x\vert{} + \vert{}x_n - x\vert{}$ 最小。
    
    - 当 $x$ 落在闭区间 $[x_1, x_n]$ 内时，这个距离之和恒等于线段长度 $x_n - x_1$。
        
    - 如果 $x$ 落在区间外部（例如小于 $x_1$），距离之和会额外多出两倍的超出距离。
        
    - 因此，对于一对点，最优的 $x$ 可以是区间 $[x_1, x_n]$ 内的任意一点。
        
2. **多点情况（区间夹逼）：** 现在我们把所有点按两端配对：最外侧的 $x_1$ 和 $x_n$ 配对，次外侧的 $x_2$ 和 $x_{n-1}$ 配对，以此类推。
    
    - 为了同时兼顾最外侧的 $x_1$ 和 $x_n$，目标值 $x$ 必须落在区间 $[x_1, x_n]$ 内。
        
    - 同理，为了兼顾次外侧的 $x_2$ 和 $x_{n-1}$，目标值 $x$ 也必须落在区间 $[x_2, x_{n-1}]$ 内。
        
    - 随着我们一层一层往内收缩，限制条件越来越严格，最终汇聚到了正中间：
        
        - **当 $n$ 为奇数时**：最后剩下正中间的一个点（即中位数 $x_{(n+1)/2}$）。此时 $x$ 只能取这个点，才能同时满足所有内层配对的最优解。
            
        - **当 $n$ 为偶数时**：最后剩下正中间的两个点 $x_{n/2}$ 和 $x_{n/2+1}$。目标值 $x$ 可以取这两个点之间的任意值，而这两个点及其之间的所有数都属于中位数的定义范围。
            

因此，从几何和成对抵消的角度来看，**中位数就是所有收缩区间的交集**，在此处总距离最短。




### 三、 证明方法二：严格的导数法（微积分）

为了严格证明，我们可以对目标函数 $f(x) = \sum_{i=1}^n \vert{}x - a_i\vert{}$ 求导。

由于绝对值函数在 $x = a_i$ 处不可导，我们可以分析其在不同区间的**导数符号（次梯度）**：

- 当 $x < a_i$ 时，绝对值展开为 $a_i - x$，其对 $x$ 的导数是 $-1$。
    
- 当 $x > a_i$ 时，绝对值展开为 $x - a_i$，其对 $x$ 的导数是 $+1$。
    

因此，函数 $f(x)$ 在任意不等于 $x_i$ 的点的导数可以表示为：

$$f'(x) = (\text{大于 } x \text{ 的元素个数}) - (\text{小于 } x \text{ 的元素个数})$$

我们来分析导数的变化趋势：

1. **当 $x$ 非常小（小于所有 $x_i$）时**：所有元素都大于 $x$，此时导数 $f'(x) = n - 0 = n > 0$（函数单调递增）。
    
2. **当 $x$ 逐渐增大**：每当 $x$ 越过一个数据点 $x_i$，就会有一个原本比 $x$ 大的元素变成比 $x$ 小。这意味着导数 $f'(x)$ 会随着 $x$ 的增大而**单调递减**（或者说阶梯式下降，图片我就通过曲线直观代替），说明这里 $f(x)$ 是一个图片类似于一个关于 $a > 0$ 一元二次方程的走势。
    
3. **寻找极小值点（导数为零或变号的位置）**：
    
    - 要让总函数 $f(x)$ 达到最小值，则就是找到关于 $f'(x) = 0$ 的位置。
        
    - 也就是说，我们需要找到这样一个 $x$，使得比它小的元素个数和比它大的元素个数大致相等。
        
    - **当 $n$ 为奇数时**：恰好当 $x$ 等于正中间的那个数（第 $\frac{n+1}{2}$ 个数）时，左边有 $\frac{n-1}{2}$ 个数，右边有 $\frac{n-1}{2}$ 个数。此时导数在这一点左侧为负、右侧为正，函数在此处取得**唯一的最小值**，这个点就是中位数。
        
    - **当 $n$ 为偶数时**：当 $x$ 处于第 $\frac{n}{2}$ 个数和第 $\frac{n}{2}+1$ 个数之间时，左边有 $\frac{n}{2}$ 个数，右边有 $\frac{n}{2}$ 个数，此时导数 $f'(x) = 0$。这意味着在这个闭区间内的任何值，导数都为 $0$，总操作数都达到相同的最小值。而这个区间恰好包含了传统意义上的中位数取值范围。
