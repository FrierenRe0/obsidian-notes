# 最长异或路径 P4551洛谷



**链接 :** [P4551 最长异或路径 - 洛谷](https://www.luogu.com.cn/problem/P4551)


## 题目大意与核心原理：

树上任意两点 $u$ 与 $v$ 之间的路径异或和，等于根节点到 $u$ 的路径异或和与根节点到 $v$ 的路径异或和的异或值。设 $d(x)$ 为根节点（如节点 1）到节点 $x$ 的路径异或和，则有：

$$\text{Path}(u, v) = d(u) \oplus d(v)$$

由于重复经过的重合路径在异或运算中会抵消（$x \oplus x = 0$），原问题等价于：**从求出的 $n$ 个点权数组 $d(x)$ 中，找出任意两个数异或的最大值**。




## 代码核心实现逻辑：

**1. 0-1 Trie 维护与二进制转换**

- **`f(x)` 函数**：利用 `bitset<32>(x).to_string()` 将十进制数值转化为高位在前、长度为 32 的二进制字符串，简化按位匹配的操作。
    
- **`insert(s)` 函数**：沿着 0-1 Trie 从根到叶子插入二进制字符串，遍历过程中若路径节点不存在，则通过 `tr.emplace_back()` 动态新建节点。
    

**2. 贪心查询最大异或值**

- **`ask(s)` 函数**：按从高位到低位的顺序遍历二进制字符串。对于当前位 `x`，优先尝试走向相反位 `find = x ^ 1` 的分支：
    
    - 若相反分支存在：说明该位异或后能产生 1，累加答案 `now += (1LL << bit)` 并沿着该分支深入；
        
    - 若相反分支不存在：只能退而求其次走向相同位的分支。
        

**3. BFS 边遍历边维护**

- 初始时将根节点 $d(1) = 0$ 插入 Trie 树。
    
- 使用队列进行层序遍历（BFS），维护从根到当前节点 `x` 的累加路径异或和 `pre_xr`。
    
- 每到达一个新节点 `next`，计算其路径值 `cur = pre_xr ^ w`：
    
    1. 先执行 `ask(s)`，计算 `cur` 与已访问过的节点路径值能构成的最大异或和，更新 `ans`；
        
    2. 再执行 `insert(s)`，将 `cur` 写入字典树供后来的节点匹配；
        
    3. 将 `next` 入队继续拓展。



## 代码展示：

```c++
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define endl '\n'
#define ctz __builtin_ctzll         // 二进制表示中末尾连续0的个数
#define clz __builtin_clzll         // 二进驻表示中先导0的个数
#define count1 __builtin_popcountll // 二进制表示中1的个数
const int mod = 1e9 + 7;
const int MOD = 998244353;
const int N = 2e5 + 7;
struct Node
{
    array<int, 2> son{};
    int ps = 0;
    int end = 0;
};

string f(int x)
{
    return bitset<32>(x).to_string();
}
void solve()
{
    int n;
    cin >> n;
    //建图
    vector<vector<pair<int, int>>> graph(n + 1);
    for (int i = 1; i < n; i++)
    {
        int u, v, w;
        cin >> u >> v >> w;
        graph[u].emplace_back(v, w);
        graph[v].emplace_back(u, w);
    }
    
    //0-1字典树
    int ans = 0
    vector<Node> tr;
    tr.emplace_back();
    auto insert = [&](string s) -> void
    {
        int cur = 0;
        for (auto &c : s)
        {
            int idx = c - '0';
            if (!tr[cur].son[idx])
            {
                int next = tr.size();
                tr.emplace_back();
                tr[cur].son[idx] = next;
            }
            cur = tr[cur].son[idx];
        }
        ++tr[cur].end;
    };
    auto ask = [&](string s) -> void
    {
        int now = 0;
        int cur = 0;
        for (int i = 0; i < 32; i++)
        {
            int bit = 31 - i;
            int x = s[i] - '0';
            int find = (x ? 0 : 1);
            if (!tr[cur].son[find])
            {
                cur = tr[cur].son[x];
            }
            else
            {
                now += (1LL << bit);
                cur = tr[cur].son[find];
            }
        }
        ans = max(ans, now);
    };

    // trie - init();
    insert(f(0));
	
	//bfs + 插入 + 查询更新
    queue<pair<int, int>> q;
    vector<int> vis(n + 1,false);
    vis[1] = true;
    q.push({1,0});
    while (!q.empty())
    {
        int len = q.size();
        for (int i = 0; i < len; i++)
        {
            auto [x, pre_xr] = q.front();
            q.pop();
            for (auto &[next, w] : graph[x])
            {
                if(vis[next]) continue;
                int cur = pre_xr ^ w;
                string s = f(cur); // 倒序
                ask(s);
                insert(s);
                //
                vis[next] = true;
                q.push({next, cur});
            }
        }
    }
    
    cout << ans;
    return;
}
signed main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(0);
    int T = 1;
    // cin >> T;
    while (T--)
    {
        solve();
    }
    return 0;
}
```

### 数据通关情况：
在常见的 **256MB 内存限制** 与 **1.0秒时间限制** 下，你当前的代码最多能处理 **$N \approx 1.5 \times 10^5 \sim 2 \times 10^5$** 规模的数据，也就是`1e5`是完全没有问题的；
